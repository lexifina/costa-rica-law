# Directriz 1-2018-06-04

Eliminación de los requisitos “copia de plano de catastro” y “certificación registral de la propiedad” para los trámites de: emisión de certificados de uso de suelo, declaración de bienes inmuebles (fincas consolidadas), permisos de construcción y visados
