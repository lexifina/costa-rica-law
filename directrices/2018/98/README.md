# Directriz 98

Durante el ejercicio económico 2018, los órganos que conforman el Presupuesto Nacional no podrán destinar los remanentes que se produzcan en diferentes subpartidas de la partida 0 Remuneraciones, para incrementar otras partidas presupuestarias
