# Directriz 36

Limitación para emitir o reformar las regulaciones existentes, cuando se establezcan trámites, requisitos y procedimientos sobre inscripciones, registros u autorizaciones, si antes no se realiza una evaluación del costo -beneficio de las regulaciones.
