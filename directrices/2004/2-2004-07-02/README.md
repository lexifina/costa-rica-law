# Directriz 2-2004-07-02

Autoriza la emisión de resoluciones de exención genéricas para la importación de equipo médico, sillas de ruedas y similares, camas especiales para hospitales, equipo ortopédico, equipo de laboratorios químico clínicos, equipo odontológicos, prótesis ...
