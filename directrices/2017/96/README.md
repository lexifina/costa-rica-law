# Directriz 96

Administración Central instituciones autónomas y semiautónomas empresas y órganos públicos deberán coordinar e informar Consejo Nacional de Facilitación del Comercio cuando participen formulen ejecuten proyectos relacionados al equipamiento pasos frontera
