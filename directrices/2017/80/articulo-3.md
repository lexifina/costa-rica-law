Artículo 3°- Las Directoras y Directores y las Juntas de Educación y Administrativas deberán coordinar con el Tribunal Supremo de Elecciones, la entrega de las instalaciones, con el fin de permitir a este órgano, acondicionar las aulas y demás espacios necesarios para ubicar los centros de votación, para los procesos de capacitación a integrantes de las juntas receptoras de votos, para la entrega y revisión de la documentación electoral, así corno para la oportuna apertura de esos centros el día de las elecciones.
