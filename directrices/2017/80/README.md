# Directriz 80

Instruye a los Directores (as) y a las Juntas de Educación y Administrativas de los Centros Educativos Públicos para que faciliten al Tribunal Supremo de Elecciones las instalaciones que ubicar los centros de votación para las Elecciones Presidenciales
