# Directriz 66

Las instituciones del Sector Transporte e Infraestructura deberán de elaboren el "Programa de Gestión Ambiental Institucional" (PGAI) de conformidad con el artículo 3° Reglamento elaboración programas de gestión ambiental institucional en sector públicor
