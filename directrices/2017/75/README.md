# Directriz 75

Los entes descentralizados deberán implementar las reformas contempladas en Decreto N° 40422 a lo interno de sus propias disposiciones reglamentarias, referente a Política Poder Ejecutivo para erradicar de sus instituciones discriminación población LGBTI
