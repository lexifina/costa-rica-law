# Directriz 7

Instruye Dirección Nacional de Pensiones adecuar sus criterios en resolución de solicitudes de pensión y jubilación de régimen de Magisterio Nacional homologando para aquellos casos que se encuentren en análoga situación a lo resuelto por Tribunal Trabajo
