# Directriz 12

Se instruye a Directores de Áreas de Conservación del Sistema Nacional de Áreas de Conservación se abstengan de convocar la celebración de asambleas para conformación de Consejos Regionales de Áreas de Conservación debido al estado de emergencia covid-19

- Número: 12
- Fecha: 2020-10-22
