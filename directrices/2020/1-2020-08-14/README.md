# Directriz 1-2020-08-14

Establece el aseguramiento de la eficacia, seguridad, estabilidad, y calidad del producto a registrar que contenga Ixodicidas se hará conforme al ReglTécnico Centroamericano RTCA 65.05.51:08 Medicamentos Veterinarios y Productos Afines.
