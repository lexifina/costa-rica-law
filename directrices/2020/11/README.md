# Directriz 11

Reforma Establece que se emitirá visados municipales del artículo 33 y 34 de la Ley 4240 únicamente para fraccionamientos simples, los cuales no deben ceder el 10% del área a fraccionar para zonas verdes o áreas de uso comunal
