# Directriz 35

La Administración Pública podrán conceder licencia sindical con goce de salario el 31/07/2009 para agremiados de Asociación Nacional de Empleados Públicos y Privados (ANEP) puedan asistir durante todo el día a la Asamblea General Ordinaria
