# Directriz 2437

Cada línea aérea en su condición de agente perceptor del impuesto debe efectuar las previsiones que correspondan en su sistema de ventas para que cuando se compre un boleto con destino a CR desde cualquier página “web” se cargue el impuesto de $15,00
