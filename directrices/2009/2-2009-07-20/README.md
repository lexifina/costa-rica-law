# Directriz 2-2009-07-20

Establece carácter obligatorio la necesidad de contar con un Sistema Oficial de Inspección Veterinaria, a todos establecimientos procesadores de productos y subproductos de origen animal que exporten o tengan intención de exportar a la República de Japón
