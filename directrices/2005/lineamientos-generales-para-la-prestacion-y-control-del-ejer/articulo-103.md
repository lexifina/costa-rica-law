Artículo 103.—Partes legitimadas para solicitar cotejo. Puede solicitar el cotejo todo aquel a quien se le oponga el documento o las partes interesadas en un proceso donde el documento se está haciendo valer o esté en litigio, asimismo el Juez respectivo y las oficinas que registran documentos notariales. Están legitimados para realizar el proceso de cotejo la DNN cuando el tomo de protocolo se encuentre en depósito del notario y el archivo notarial cuando el mismo esté bajo su custodia.
