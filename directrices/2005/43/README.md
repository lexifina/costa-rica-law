# Directriz 43

El INCOFER en coordinación con el Ministerio de Obras Públicas y Transportes deberá iniciar a partir del 7 de octubre de 2005 y por un plazo de seis meses un plan piloto para la movilización de un tren metropolitano entre Pavas y la Universidad Latina
