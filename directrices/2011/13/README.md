# Directriz 13

No se autoriza creación de plazas ni la utilización de plazas que queden vacantes, exceptuando solo aquellos casos que son de interés para el Estado, se autoriza a vender todos los activos que resulten innecesarios y reducir un 20% de sus presupuestos
