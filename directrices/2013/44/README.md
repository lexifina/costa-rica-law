# Directriz 44

Las instituciones de la Administración Pública no realizarán nuevos desarrollos de sistemas electrónicos de compras públicas hasta que la Comisión del Sistema Nacional de Compras Públicas brinde un informe sobre las recomendaciones del proceso a seguir
