# Directriz 1-2013-11-04

Para efectos de aplicación de artículo 9 de Regla para percepción control administración y fiscalización del impuesto del 5% sobre el valor de los pasajes cuyo origen de ruta sea CR la aerolíneas deberán declarar y liquidar impuesto percibido mensualmente
