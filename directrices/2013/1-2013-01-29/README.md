# Directriz 1-2013-01-29

Todo establecimiento que cuente con Certificado Veterinario de Operación (CVO) y que a la fecha no haya actualizado la renovación del Registro de CVO, se le concede un plazo transitorio de seis meses para que proceda a actualizar la información
