# Directriz 50

Las instituciones del sector público no deberán gestionar ni aceptar el ofrecimiento de utilizar vuelos aéreos suministrados por personas físicas o jurídicas de sector privado nacional o internacional para realización de giras y viajes de sus funcionarios
