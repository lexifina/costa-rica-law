# Directriz 2-2013-11-04

Para aplicación de artículo 8 de Regl. percepción control adm. de impuesto de $15 la aerolíneas como agentes de percepción deberán declarar y liquidar el impuesto percibido mensualmente mediante declaración jurada simple electrónica u otro medio magnético
