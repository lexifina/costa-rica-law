# Directriz (2008-04-08)

Se establece que el incumplimiento de cualquiera de las normas vigentes que regulen la actividad de casinos, será considerada a su vez, como un incumplimiento de las obligaciones del régimen de la declaratoria turística (acuerdo SJD-204-2008)
