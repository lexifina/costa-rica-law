# Directriz 1-2006-03-22

Instituciones Sector Público comprendidas en artículos 1° y 29 Ley 8131, Dirección General de Tributación y de Aduanas deberán atender información de Contabilidad Nacional para que instituciones públicas atiendan principios-normas en ámbito gubernamental
