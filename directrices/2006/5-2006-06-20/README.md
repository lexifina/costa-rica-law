# Directriz 5-2006-06-20

El Comité Permanente de Desarrollo Organizacional (CODES) será una instancia técnica colegiada, matricial, interdisciplinaria y polifuncional, cuyo objetivo es apoyar la realización de iniciativas tendentes a mejorar la prestación de servicios
