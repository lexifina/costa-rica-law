# Directriz 4-2024-05-16

Regula el registro, en el sistema SIBINET, de las computadoras estacionarias y el tratamiento de sus accesorios no patrimoniales ("Mouse" y "Teclado"), adquiridos junto con la compra por contratación, de las computadoras estacionarios
