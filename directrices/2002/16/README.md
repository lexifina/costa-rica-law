# Directriz 16

Establece que el gasto total que realice cada institución descentralizada o empresa pública, únicamente podrá incrementarse en un 5.9% con respecto al gasto efectivo del año 2002.

- Tipo: Directriz
- Número: 16
- Fecha: 2002-12-16
- Ente emisor: Poder Ejecutivo
