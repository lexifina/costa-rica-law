# Directriz 1-2010-01-07

Para efectos artículo 6 regl. Percepción, Control, Adm. y Fiscalización del Imp. 5% sobre Valor Pasajes cuyo Origen de Ruta sea C.R. se debe entender empresa transporte responsable por importe recaudado aquella traslada pasajero de C.R. hacia el exterior
