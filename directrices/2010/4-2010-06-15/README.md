# Directriz 4-2010-06-15

Instituciones que forman parte Adm. Pública tanto centralizada como descentralizada en plazo máximo 2 meses deberán realizar estudio pormenorizado para determinar cuáles órganos interinstitucionales Ad Hoc forman parte mediante delegados o representantes
