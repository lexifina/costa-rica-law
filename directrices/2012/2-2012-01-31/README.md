# Directriz 2-2012-01-31

Autoriza al Colegio de Médicos Veterinarios a expedir y a vender a las farmacias veterinarias las órdenes de compra indicadas por el artículo 40 del Reglamento de Registro y Control de Medicamentos Veterinarios (decreto ejecutivo N° 28861)
