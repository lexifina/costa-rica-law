# Directriz 35

Establece que en toda política, plan, programa o proyecto relacionado con materia de ordenamiento territorial y desarrollo urbano del GAM se debe tomar en cuenta el Proyecto de Planificación Urbana Regional de la Gran Área Metropolitana (PRUGRAM)
