# Directriz 64

Todos los Entes y Órganos Públicos, realizarán las gestiones necesarias ante la Dirección General de Administración de Bienes y Contratación Administrativa con el fin de utilizar los Convenios Marco que tiene a disposición el Ministerio de Hacienda
