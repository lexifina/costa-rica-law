# Directriz 6

Reforma directriz que elimina Certificado de Uso de Suelo como requisito para otorgar Certificado Veterinario de Operación para establecimientos que se encuentren ubicados en cantones y distritos que no cuentan con Plan Regulador o Reglamento zonificación
