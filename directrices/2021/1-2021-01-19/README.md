# Directriz 1-2021-01-19

Prorroga la vigencia de la directriz N° 0012-2020 "Se instruye a Directores de Áreas de Conservación se abstengan de convocar la celebración de asambleas para conformación de Consejos Regionales de Áreas de Conservación por estado de emergencia Covid 19"
