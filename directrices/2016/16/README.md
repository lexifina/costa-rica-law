# Directriz 16

Instruye Dirección de Medicamentos Veterinarios que clasifique los medicamentos que contengan como ingrediente activo la ivermectina, doramectina, moxidectina y abamectina en el Grupo 3 de Medicamentos Veterinarios conforme el decreto ejecutivo N° 28861
