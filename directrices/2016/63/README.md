# Directriz 63

Establece que las instituciones que conforman el sector transporte deben elaborar un Plan de Capacitación a que refiere el Capítulo 1 del Plan Nacional de Transportes de Costa Rica 201 1-2035, oficializado mediante el Decreto Ejecutivo Nº 37738-MOPT
