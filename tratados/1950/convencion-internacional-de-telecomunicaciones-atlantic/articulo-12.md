ARTICULO XII
Reglamento Interior de las Conferencias
1º—Antes de empezar sus deliberaciones, cada conferencia adoptara un reglamento interior de conformidad con el cual se organizaran y llevarán a cabo las discusiones y el trabajo.
2º—Para este fin, cada conferencia tomara como base las disposiciones del Reglamento General agregado a este Convenio, con las modificaciones que a bien tenga hacer.
