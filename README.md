# Costa Rica law (work in progress)

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law: this is Costa Rica's national law, which global-law reads at `costa-rica/national/acts/`.

Status: building. The national legislation of Costa Rica (the Constitution and the laws), with every dated
version kept by SINALEVI (Sistema Nacional de Legislación Vigente, Procuraduría General de la República,
https://sinalevi.go.cr), as a git history: one commit per reforming law per in-force day. Private.
