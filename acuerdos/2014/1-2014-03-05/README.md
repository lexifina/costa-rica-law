# Acuerdo 1-2014-03-05

Aprueba incremento por costo de vida en 0.43% al monto de pensión para personas que reciben una pensión desde 1 julio de 2013 o antes y para aquellas que reciben una pensión después de esa fecha y hasta el 31 de diciembre 2013 su aumento será proporcional
