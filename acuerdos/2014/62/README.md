# Acuerdo 62

Convoca con carácter transitorio a la Reserva de las Fuerzas de Policía, como cuerpo auxiliar extraordinario, con carácter ad honorem, para atender y coordinar con las autoridades de policía, las labores de vigilancia y protección de la seguridad pública
