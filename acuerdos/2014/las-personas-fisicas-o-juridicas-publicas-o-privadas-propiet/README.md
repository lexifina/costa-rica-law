# Acuerdo (2014-04-04)

Las personas físicas o jurídicas públicas o privadas propietarias o administradoras de bases de datos deberán adecuar sus procedimientos y reglas de actuación para cumplir con Ley N° 8968 Protección de la Persona frente tratamiento datos personales
