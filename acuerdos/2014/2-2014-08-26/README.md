# Acuerdo 2-2014-08-26

Aprueba incremento por costo de vida en 2.6% al monto de pensión para personas que reciben pensión desde 01/01/2014 o antes y para aquellas que reciben una pensión después de esa fecha y hasta el 30 de junio del 2014 su aumento será proporcional
