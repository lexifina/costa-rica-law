# Acuerdo 26

Se instruye Consejo Nacional de Áreas de Conservación en conjunto con los representantes de las organizaciones de la comunidad de Cahuita se establezcan las condiciones técnicas y legales para el modelo de Gobernanza de comanejo en Parque Nacional Cahuita
