# Acuerdo (2010-07-27)

En virtud de interpretación artículo 142 Código Electoral, se prohíbe a instituciones Poder Ejecutivo, la administración descentralizada y empresas del Estado, alcaldías y concejos municipales, difundir mediante cualquier medio información publicitaria
