# Acuerdo 27

Deja sin efecto las resoluciones R-DGTCC-100-2006 en la que se establece obligaciones y sanciones para las empresas, transportistas, distribuidores y comercializadores de gas licuado y la R-DGTCC-106-2005 sobre el manejo y uso de los cilindros portátiles
