# Acuerdo 5469

Reduce en ciento cincuenta puntos base la Tasa de Política Monetaria de manera que se ubique en 7,50% anual y reduce en ciento cincuenta puntos base la tasa de interés bruta anual para depósitos a un día plazo, de manera que se ubique en 4,25%
