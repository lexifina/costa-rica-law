# Acuerdo (2010-01-25)

Deroga el acuerdo N° 146 del 7 de Junio de 1962 que declara que la obra conocida como Puesto Fronterizo "Alfonso Monge Ramírez", fue entregada desde el 29 de abril de 1962 al Instituto Costarricense de Turismo, para su conservación y Administración
