# Acuerdo (2010-09-01)

Pone en ejecución un programa de acumulación de reservas internacionales y se instruye al Comité de Seguimiento del Mercado Cambiario para que, durante el período comprendido entre el 02/09/2010 y el 31/12/2011, adquiera divisas en el MONEX
