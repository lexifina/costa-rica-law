# Acuerdo 104

Reforma acuerdo que autoriza el traspaso de licencia comercial inactiva con sustitución de embarcación independientemente de la clasificación de flota a la que pertenezca, excepto flota semi industrial dedicada a la pesca de camarón con red de arrastre
