# Acuerdo (2017-12-06)

Los procedimientos disciplinarios seguidos contra peritos, ejecutores, traductores, intérpretes y curadores procesales y procedimientos cobro administrativo para recuperación patrimonial del Poder Judicial estarán a cargo de Sub Directora Jurídica
