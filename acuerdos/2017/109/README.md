# Acuerdo 109

Establece veda total para la pesca en pequeña, veda para la pesca semi-industrial camaronera de arrastre, aprueba pesca de barracudas o candado (Sphyraena ensis) con anzuelo N° 6 y N° 7 y sin utilizar carnada viva
