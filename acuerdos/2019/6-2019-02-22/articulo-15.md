Artículo 15°- De la conformidad con el Sistema Nacional para la Calidad: El Programa Nacional de Etiquetado Ambiental y Energético está en conformidad con el Sistema Nacional para la Calidad. Para todos los efectos del Programa. los procedimientos para otorgar el derecho de uso de las EACR o las EECR se basan en los principios y definiciones establecidos por el Sistema Nacional para la Calidad. mediante la ley Número 8279 y sus modificaciones, así como las normas que se establezcan a lo interno del Sistema Nacional para la Calidad y que tengan relación con el etiquetado ambiental o energético.
