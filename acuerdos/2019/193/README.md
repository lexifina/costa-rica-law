# Acuerdo 193

Se acuerda no autorizar la realización de transferencias presupuestarias a sujetos públicos, privados o fideicomisos que potencialmente pudieran ser beneficiarios de tales transferencias

- Número: 193
- Fecha: 2019-11-22
