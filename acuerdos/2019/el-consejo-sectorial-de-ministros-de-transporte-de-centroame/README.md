# Acuerdo (2019-05-13)

El Consejo Sectorial de Ministros de Transporte de Centroamérica (COMITRAN) aprobó el 28 de septiembre de 2018 la Resolución N° 05-2018 (COMITRAN XXXIX). Esta norma entró en vigor el 28 de octubre de 2018 para validar las Reglas de Aviación Civil Maestras (MRAC). El documento integra 10 reglamentos conjuntos sobre licencias, mantenimiento, operaciones aéreas y seguridad
