# Acuerdo 6120

Concede Permiso de Atraque y Permanencia en Puerto y Desembarque de las Tripulaciones de las Embarcaciones en Puertos Costarricenses, tanto del Mar Caribe como del Océano Pacífico, tocando los Puertos de Golfito, Caldera, Limón y Moín.
