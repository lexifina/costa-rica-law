# Acuerdo 433

Establece que los permisionarios con licencia para la pesca artesanal con trasmallo en el Golfo de Nicoya solo se les permitirá una altura máxima de 50 mallas de alto con un largo de 600 metros lineales en la Zona A del Golfo de Nicoya
