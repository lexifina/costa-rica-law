# Acuerdo 1067

Convoca con carácter transitorio y ad honorem a la Reserva de las Fuerzas de Policía, como cuerpo auxiliar extraordinario, para atender y coordinar con autoridades de policía las labores de vigilancia y protección de la seguridad pública
