# Acuerdo 453

Establece como obligatorio el uso del dispositivo excluidor de peces del tipo ojo de pescado en la realización de las faenas de pesca por parte de la flota semiindustrial camaronera costarricense tanto en la pesca costera como en la pesca de profundidad
