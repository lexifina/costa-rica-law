# Acuerdo 223

Autoriza a la Presidencia Ejecutiva para que se sustituya la autorización manuscrita por autorización digital en los procesos de registro y aprobación de las licencias de pesca, autorizaciones, permisos y concesiones emitidas por el INCOPESCA
