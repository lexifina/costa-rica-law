# Acuerdo 462

Se autoriza el uso de atarraya únicamente para captura de sardina y anchoveta para ser utilizada como carnada para sus propias faenas a embarcaciones de la flota pesquera comercial pequeña escala con artes de pesca autorizados de cuerda de mano y línea
