# Acuerdo (2009-07-15)

Reduce en cien puntos base la Tasa de Política Monetaria de manera que se ubique en 9% anual y reduce en cincuenta puntos base la tasa de interés bruta anual para depósitos a un día plazo, de manera que se ubique en 7,25%
