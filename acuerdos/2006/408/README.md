# Acuerdo 408

La emisión de Lotería Tiempos para los días martes y viernes se establezca en 40.000 billetes para cada sorteo y incorpora un sorteo de la Lotería Tiempos para los domingos a partir del 8 de octubre y hasta el 3 de diciembre del 2006
