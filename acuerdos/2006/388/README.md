# Acuerdo 388

Emite Directrices N° PE-001-2006 y PE-002-2006, el Instituto Costarricense de Pesca y Acuicultura refuerza medidas para la descarga de tiburones en los distintos puertos costarricenses como parte de la lucha para erradicar la práctica Aleteo
