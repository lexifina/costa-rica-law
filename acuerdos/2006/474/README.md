# Acuerdo 474

Se autoriza el transborde de productos pesqueros de cualquier especie permitida, por parte de embarcaciones costarricenses dedicadas a la pesca comercial, en el tanto dichas embarcaciones cuenten con la autorización previa y respectiva del INCOPESCA
