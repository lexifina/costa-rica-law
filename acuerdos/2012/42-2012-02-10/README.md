# Acuerdo 42-2012-02-10

Las embarcaciones de bandera extranjera de palangre que descarguen productos pesqueros en puertos nacionales, debidamente autorizados en el Litoral Pacífico, estarán obligadas de previo a contar con un sistema de seguimiento satelital
