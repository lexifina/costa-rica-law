# Acuerdo 485

Declaratoria de las áreas de zona marítimo terrestre que no forman parte del Patrimonio Natural del Estado, para el cantón de Golfito, declara de aptitud turística los sectores de zona marítimo terrestre del frente costero del cantón de Golfito
