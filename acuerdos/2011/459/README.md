# Acuerdo 459

Autoriza cobro de una tarifa de $15,00 por período de un mes calendario o por días menores a un mes, para los carné de pesca turística y deportiva nacionales y extranjeros de forma transitoria o temporal, hasta el mes de abril del 2012
