# Acuerdo 246

Convoca con carácter transitorio, a la Reserva de las Fuerzas de Policía, como cuerpo auxiliar extraordinario, con carácter ad honórem, para atender y coordinar con las autoridades de policía, las labores de vigilancia y protección de la seguridad pública
