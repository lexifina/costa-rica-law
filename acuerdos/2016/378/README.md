# Acuerdo 378

Prohíbe la retención a bordo, transbordo, descarga, o almacenamiento, de cualquier parte o del cuerpo entero de tiburones sedosos (Carcharhinus falciformis) capturados en el Área de la Convención por buques de cerco, con bandera o licencia de pesca
