# Acuerdo 3-2015-05-14

Sólo pueden traducir a otro idioma, aquellos traductores oficiales inscritos como tales ante el Ministerio de Relaciones Exteriores y no los notarios, quienes lo pueden hacer únicamente de otro idioma al español
