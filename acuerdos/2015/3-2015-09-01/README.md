# Acuerdo 3-2015-09-01

Aprueba incremento en un 0.1% para las personas que reciben una pensión antes o a la fecha del 01/01/2015 y para aquellas que reciben una pensión después de esa fecha y hasta el 30 de junio de 2015 su aumento sea forma proporcional al tiempo de disfrute
