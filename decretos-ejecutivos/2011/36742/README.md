# Decreto Ejecutivo 36742

Autoriza al Centro de Investigación y Conservación del Patrimonio Cultural del Ministerio de Cultura y Juventud para que destine recursos presupuestarios, materiales y humanos para intervenir el edificio conocido como “Botica Solera”
