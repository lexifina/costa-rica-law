# Decreto Ejecutivo 36597

Pone vigencia decisión la Comisión de Libre Comercio en relación ciertas Reglas de Origen Mercancías Textiles y Confección, mediante la cual se establecen correcciones reglas de origen específicas contenidas Anexo 4.1 (Reglas de Origen Especificas) TLC
