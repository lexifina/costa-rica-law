# Decreto Ejecutivo 36480

Declara Estado de Emergencia Nacional la situación actual de los quirófanos del Hospital San Juan de Dios y de Interés Público y Nacional las acciones que realicen las Autoridades Públicas para solucionar dicho problema sanitario
