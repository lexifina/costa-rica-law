# Decreto Ejecutivo 36408

Declara Emergencia Sanitaria la situación actual del Post Cierre del Relleno Sanitario de Río Azul por la falta de extracción del biogás y de Interés Público y Nacional las acciones que realicen las Autoridades Públicas para solucionar dicho Problema
