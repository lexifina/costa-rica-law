# Decreto Ejecutivo 36394

Aprueba modelo Curricular para Liceo de Costa Rica y implementación del Bachillerato Internacional y el Reconocimiento de la Oferta Educativa Pública diferencia para varones y otorga al liceo de Costa Rica el carácter de "Colegio Laboratorio”
