# Decreto Ejecutivo 43191

Declara de interés público a la población afrocostarricense, su identidad cultural, idioma, tradición histórica, cultura y cosmovisión y creación de la mesa para el proceso de reconocimiento de pueblos tribales afrocostarricenses
