# Decreto Ejecutivo 43136

Promulga acuerdo bajo la modalidad de canje de notas con el República Federal de Alemania sobre el proyecto Fomento de la estrategia de neutralidad climática de Costa Rica como modelo de desarrollo bajo en emisiones de carbono (Fase II)"
