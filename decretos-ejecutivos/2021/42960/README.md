# Decreto Ejecutivo 42960

Publica resolución N° 427-2020 (COMIECO-XCII) de 27/10/2010 aprueba las aperturas arancelarias y modificación de Derechos Arancelarios a la Importación para algunas placas, láminas, hojas y tiras plásticas, clasificadas en el inciso arancelario 3920.49.31
