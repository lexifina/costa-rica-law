# Decreto Ejecutivo 43662

Deroga declaratorias de utilidad pública a las asociaciones administradora del acueducto potable y alcantarillado sanitario de mora de Turrialba, de seguridad y embellecimiento de carreteras nacionales y pro hospital de Pérez Zeledón
