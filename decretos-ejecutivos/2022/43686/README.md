# Decreto Ejecutivo 43686

Declara e incorporar al Patrimonio Histórico-Arquitectónico de Costa Rica, bajo la categoría de Monumento, el inmueble conocido como "Área Rectora de Salud de Santo Domingo de Heredia (Antigua Unidad Sanitaria)"
