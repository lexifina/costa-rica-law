Artículo 32°. - Establecimientos con varios tipos de servicios de salud: Si en una misma edificación, se pretende instalar varios servicios de salud, ya sea del mismo o diferente tipo, se debe tramitar de forma independiente la solicitud del permiso de habilitación para cada servicio de salud; de cumplir con los requisitos establecidos se debe emitir un permiso de habilitación individual para cada servicio de salud.
