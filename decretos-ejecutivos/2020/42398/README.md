# Decreto Ejecutivo 42398

Oficializa estrategia para identificar actividades mínimas con la adquisición del derecho de vía y relocalización de servicios públicos que deben ser realizadas en cada una de las etapas del ciclo de vida de proyectos para desarrollo de infraestructura
