# Decreto Ejecutivo 42751

Reglamento autorización sanitaria para el desalmacenaje y adquisición de medicamentos no registrados por entidades estatales con funciones de salud pública o seguridad social y para la autorización del desalmacenaje en caso de necesidad pública o de emerg
