# Decreto Ejecutivo 42596

Amplia la vigencia del plazo del decreto de emergencia Nº 39056-MP del 30/06/2015 que declaró estado de emergencia nacional la situación provocada por condiciones de temporal y paso de un sistema de baja presión que generó abundantes lluvias
