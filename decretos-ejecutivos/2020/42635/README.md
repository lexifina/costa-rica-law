# Decreto Ejecutivo 42635

Declara e incorpora al Patrimonio Histórico-Arquitectónico de Costa Rica bajo la categoría de edificación el inmueble denominado "Antigua Estación de Ferrocarril al Pacífico ubicado en Escobal de Atenas"
