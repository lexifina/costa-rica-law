# Decreto Ejecutivo 42753

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste de cero coma treinta y cinco por ciento (0,35%)

- Número: 42753
- Fecha: 2020-12-07
- Ente emisor: Poder Ejecutivo
