# Decreto Ejecutivo 42560

Disposiciones dirigidas al Gobierno Central sobre la necesidad de renegociar a la baja los contratos de adquisición, arrendamiento o prestación de servicio por licenciamiento y/o mantenimiento de Software y arrendamiento o leasing de servicios informático
