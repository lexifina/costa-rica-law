# Decreto Ejecutivo 11-1952-02-20

El Registro Público inscribirá libre de derechos las escrituras en las que se consignen traspasos al Estado de lotes para la ubicación del Aeropuerto Internacional de “ El Coco”

- Número: 11
- Fecha: 1952-02-20
