# Decreto Ejecutivo (1914-07-25)

Ratifica Tratado para someter a una Comisión Internacional las desavenencias de cualquier naturaleza que no estén comprendidas en tratados de arbitraje o compromisos existentes y no se solucionaron por vía diplomática
