# Decreto Ejecutivo 30961

Mantiene medida cautelar que dispone la obligación del Ministerior de Ambiente y Energía de verificar la efectividad de las acciones adoptadas para el mantenimiento y el desarrollo de áreas destinadas a los árboles de Almendro.
