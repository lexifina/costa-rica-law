# Decreto Ejecutivo 30257

Promulgar teniéndo como vigente, el Acuerdo de Cooperación Técnica y Financiera suscrito entre la Fundación Suiza para la Cooperación al Desarrollo Técnico y el Instituto Costarricense de Enseñanza Radiofónica para el Proyecto Educacional Ambiental.
