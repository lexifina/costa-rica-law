Artículo 4º—Composición química.
4.1 La aleación debe cumplir los requisitos especificados en la Tabla 1, para los elementos principales.
4.2 Los límites de esta especificación no excluyen la presencia de otros elementos. Se pueden establecer límites para elementos no mencionados, mediante acuerdo entre el fabricante o proveedor y el comprador. Como residuo se pueden dar cobre o cinc y se pueden tomar como la diferencia entre la suma de todos los elementos analizados y el 100%. Cuando todos lo elementos nombrados en la Tabla 1 se han analizado, la suma de ellos debe ser como se indica a continuación:
Cobre más elementos nombrados: 99,3% mínimo.
4.3 Se reconoce que en aleaciones de cobre fundido puede haber presencia de elementos residuales. Se deben realizar análisis de dichos elementos sólo cuando esté especificado en la orden de compra (Especificación ASTM B 824).
