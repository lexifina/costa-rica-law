# Decreto Ejecutivo 30861

Reforma Decreto Ejecutivo N° 30208-MI-MIVAH, que Declara de interés para el Estado los proyectos de vivienda que se encuentran en trámite ante las distintas entidades autorizadas del Sistema Financiero Nacional para la Vivienda
