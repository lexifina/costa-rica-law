# Decreto Ejecutivo 30217

Reforma decreto que Autoriza a Poder Ejecutivo para que por Decreto elaborado por el Ministerio de Hacienda continúe realizando las modificaciones presupuestarias de la Ley de Presupuesto Ordinario Y Extraordinario para el ejercicio fiscal del año 2001
