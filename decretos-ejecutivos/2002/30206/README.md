# Decreto Ejecutivo 30206

Crea una Comisión para que genere directrices, coordine y evalúe, los diferentes componentes del Programa Nacional de Prevención y Atención Integral del Cáncer Cérvico-Uterino y de Mama, con el objeto de garantizar su continuidad y sostenibilidad.
