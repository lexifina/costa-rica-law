# Decreto Ejecutivo 30236

Reforma al decreto que ordena que todo el Gobierno Central se proponga diligentemente prevenir y combatir el uso ilegal de programas de cómputo, con el fin de cumplir con las disposiciones sobre derecho de autor que establece la Ley N° 6683 y sus reforma
