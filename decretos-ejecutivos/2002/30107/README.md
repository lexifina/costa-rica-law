# Decreto Ejecutivo 30107

Determina las exepciones del pago de la tarifa del servicio de transporte colectivo regular de personas, mediante un régimen de exención total o parcial del pago de los adultos mayores de 65 años, según los desplazamientos efectua este tipo de usuarios
