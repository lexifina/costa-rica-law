# Decreto Ejecutivo 30634

Reduce a un 5% la aplicación de la tarifa de Impuesto Selectivo de Consumo a las partidas 3208, 3209, 3210, 321100000, 3212 y 3214 del anexo a la Ley N° 4961, referente a pinturas, barnices, revestimientos y afines.
