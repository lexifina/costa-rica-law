# Decreto Ejecutivo 30152

De acuerdo con el Pacto Internacional de Derechos Civiles y Políticos, se reconoce la competencia del Comité para recibir y examinar las comunicaciones enviadas por un Estado Parte que alegue el imcumplimiento de otro Estado Parte al Pacto
