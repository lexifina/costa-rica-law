# Decreto Ejecutivo 30176

Declara de interés público y nacional el XVI Congreso Latinoamericano de Bioquímica Clínica y XIII Congreso Nacional de Microbiología, Parasitología y Patología Clínica, así como las actividades que respecto de ellos realice el Colegio de Microbiólogos
