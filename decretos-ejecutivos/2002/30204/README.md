# Decreto Ejecutivo 30204

Establece que empresas nacionales o internacionales de dicadas a la cuantificación de pesos y volúmenes de mercancía, para fines de importación o exportación, deben encontrarse acreditadas ante el Ente Nacional de Acreditación, en seis meses
