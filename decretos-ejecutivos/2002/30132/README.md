# Decreto Ejecutivo 30132

De acuerdo con la Convención contra la tortura y otros tratos o penas crueles, inhumanos o degradantes, se reconoce la competencia del Comité para recibir y examinar las comunicaciones enviadas por personas que aleguen ser víctimas por un Estado parte
