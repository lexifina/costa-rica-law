# Decreto Ejecutivo 30708

Levanta en todo el Litoral Pacífico incluyendo Quepos y Parrita, la veda para la piangua (Anadara tuberculosa), así como para las especies de almejas (Ptrothotaca asperrima, Donax sp.) y mejillones (Mittella guyanensis).
