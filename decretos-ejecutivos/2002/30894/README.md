# Decreto Ejecutivo 30894

Excepciona la aplicación de suspensión de recibir solicitudes para trámites mineros contenidos el el decreto que Crea la Comisión de Evaluación y Diagnóstico de las Actividades Geológicas y Mineras, a solicitud del Ministerio Seguridad Pública
