# Decreto Ejecutivo 30598

Autoriza la importación de veintiséis mil setecientas cincuenta y seis toneladas métricas (26.756 TM), de maíz blanco, con una tarifa de cero por ciento (0%) de Derechos Arancelarios a la Importación

- Número: 30598
- Fecha: 2002-07-17
- Ente emisor: Poder Ejecutivo
