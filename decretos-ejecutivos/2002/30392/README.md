# Decreto Ejecutivo 30392

Consolidad a la Unidad de Equidad de Género del Ministerio de Trabajo y Seguridad Social, para que su alcance funcional sea a todos los niveles, políticas, tareas, funciones y actividades que desarrolle el Ministerio de Trabajo y Seguridad Social
