Artículo 8º—Prueba adicional y rechazo.
8.1 Si los resultados de una prueba no satisfacen los requisitos de este reglamento, la prueba se debe realizar nuevamente previo acuerdo entre el comprador y el proveedor. No debe existir ninguna decisión que disminuya los requisitos mínimos de este reglamento mediante la omisión de pruebas que sean parte de la misma, sustitución o modificación de un método de prueba o el cambio en las especificaciones límites. Al realizar la nueva prueba se deben satisfacer los requisitos de este reglamento y se deben respetar los métodos de prueba diseñados. Si en la realización de una nueva prueba, se presenta falla, todo el lote representado por la muestra se debe rechazar.
