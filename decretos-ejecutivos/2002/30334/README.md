# Decreto Ejecutivo 30334

Determina que los estudios que se realicen en el Centro Educativo Santa Rosa de Lima, situado en Santa Rosa de Santo Domingo de Heredia, costado este de la iglesia católica, tendrán correspondencia con el Sistema Educativco Estatal
