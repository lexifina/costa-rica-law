# Decreto Ejecutivo 30687

Convoca, con carácter transitorio, a la Reserva de las Fuerzas de Policía, como cuerpo auxiliar extraordinario, con carácter ad honorem, para colaborar en la vigilancia, con ocasión de los Juegos Deportivos Nacionales Nicoya 2002
