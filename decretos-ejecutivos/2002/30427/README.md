# Decreto Ejecutivo 30427

Reforma el Decreto Ejecutivo Nº 27168, para que se tenga como integrante de la Junta Directiva del Consejo de Seguridad Vial, al Lic. Tobías D’ Ambrosio Umaña, como delegado del Presidente de la Caja Costarricense de Seguro Social ante esa Junta.
