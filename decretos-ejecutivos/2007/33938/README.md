# Decreto Ejecutivo 33938

Autoriza importación de ciento cuarenta y siete mil ochocientas cuarenta y siete toneladas métricas de arroz en granza (147.847 T.M.), con una tarifa de cero por ciento (0%) de Derechos Arancelarios a la Importación

- Fecha: 2007-08-09
