# Decreto Ejecutivo 33700

Se autoriza la importación de dieciocho mil kilogramos de arroz (18.000 kg.), con una tarifa de cero por ciento (0%)

- Tipo: Decreto Ejecutivo
- Número: 33700
- Fecha: 2007-03-02
- Ente emisor: Poder Ejecutivo
