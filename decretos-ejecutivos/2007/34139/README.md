# Decreto Ejecutivo 34139

Regula el registro, la fabricación, la formulación, el reempaque, el almacenamiento, la venta, la mezcla, la comercialización y uso, de materia prima o producto formulado, de los productos que contengan el plaguicida agrícola dicloruro de paraquat
