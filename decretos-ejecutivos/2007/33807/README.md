# Decreto Ejecutivo 33807

Autoriza la importación como desabasto adicional al volumen autorizado de treinta mil quinientas cincuenta y un toneladas métricas (30551 TM), con una tarifa arancelaria de cero por ciento (0%)

- Número: 33807
- Fecha: 2007-05-10
