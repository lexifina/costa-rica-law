# Decreto Ejecutivo 33834

Declara estado de emergencia nacional la situación provocada por el fenómeno meteorológico que generó una fuerte actividad lluviosa con vientos y aguaceros, lo que ocasionó serias inundaciones y deslizamientos en los cantones de Belén, Flores, Heredia...
