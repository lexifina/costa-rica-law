# Decreto Ejecutivo 34211

Declara de interés nacional y de alta prioridad los proyectos de iniciativa pública o privada que promuevan procesos de desalinización del agua marina para su posterior aprovechamiento para el consumo humano, riego y demás usos del recurso hídrico
