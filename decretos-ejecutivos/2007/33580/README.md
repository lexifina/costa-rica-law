# Decreto Ejecutivo 33580

Publica Resolución N° 189-2006 (COMIECO-XLI) Aprueba modificaciones a los Derechos Arancelarios a la importación el cual forma parte integrante del Anexo “A” del Convenio sobre el Régimen Arancelario y Aduanero Centroamericano
