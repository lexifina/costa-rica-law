# Decreto Ejecutivo 33719

Declara de interés público la celebración de XIII Asamblea Anual del Grupo Regional de América Latina y del Caribe del Instituto Mundial de Cajas de Ahorro (IMCA), así como el debate relacionado con “Las mejores prácticas en la financiación de las PYMES"
