# Decreto Ejecutivo 33965

Convoca conforme lo solicitado por Ministro de Seguridad Pública y con carácter de transitorio a la Reserva de las Fuerzas de Policía, como cuerpo auxiliar extraordinario, con carácter ad honores, para atender y coordinar con las autoridades de policía
