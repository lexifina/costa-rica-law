# Decreto Ejecutivo 33882

Declara interés público y nacional, actividades Asociación Costarricense para la Prevención y el Tratamiento de la Aterosclerosis, con motivo Simposio “Factores de Riesgo Cardiovascular, Discusión de Casos Clínicos y su Aplicación en la Práctica Diaria”
