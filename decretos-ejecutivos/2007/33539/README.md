# Decreto Ejecutivo 33539

Declara de interés público y cultural la “Reunión Plenaria del Círculo de Montevideo” con el fin de abordar el tema “Estabilidad democrática y apertura: Factores imprescindibles para la América Latina del Siglo XXI”
