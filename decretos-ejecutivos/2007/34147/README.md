# Decreto Ejecutivo 34147

Regula el registro, la importación, el redestino, la fabricación, la formulación, el reempaque, el almacenamiento, la venta, la mezcla, la comercialización y uso, de materia prima o producto formulado, de los productos que contengan el plaguicida agrícol
