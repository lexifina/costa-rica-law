# Decreto Ejecutivo 34019

Conforma Comisión cuya integración respete lo dispuesto por el artículo 1 de la Ley Nº 7270 para que analice la viabilidad técnica de darle una nueva ubicación a la escultura del ex presidente José Figueres Ferrer
