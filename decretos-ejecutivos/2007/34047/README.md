# Decreto Ejecutivo 34047

Encomienda a Unidades de Recursos Humanos, el registro, control y aprobación del pago horas extraordinarias trabajadas en programas y subprogramas presupuestarios diferentes o por convenios interinstitucionales. Deroga decreto 28947
