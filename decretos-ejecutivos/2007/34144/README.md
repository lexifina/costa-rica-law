# Decreto Ejecutivo 34144

Prohíbe para uso agrícola, el registro, la importación, redestino, fabricación, la formulación, el reenvase, el reempaque, el almacenamiento, la comercialización y el uso, de materia prima o producto formulado que contenga Monocrotofos
