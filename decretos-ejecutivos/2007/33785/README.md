# Decreto Ejecutivo 33785

Declara de interés público y nacional, las actividades que llevará a cabo la Asociación Costarricense de Congresos Odontológicos, motivo de la celebración del XXII Congreso Científico Odontológico y XIII Premio de Investigación Dr. Ramón García Valverde
