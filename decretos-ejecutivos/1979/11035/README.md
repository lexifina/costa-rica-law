# Decreto Ejecutivo 11035

Concede a la firma "Del Campo, Alimentos Congelados, Sociedad Anónima exención del 50% de impuestos arancelarios y demás gravámenes conexos, incluyendo los derechos consulares, sobre la importación de envases, materias primas y productos semielaborados
