# Decreto Ejecutivo 35543

Declara situación de pobreza coyuntural la condición de los pescadores sujetos a las restricciones y condiciones de veda para el Golfo de Nicoya, según el acuerdo A.J.D.I.P./200-2009 y acuerdo N° A.J.D.I.P 227 del 2009
