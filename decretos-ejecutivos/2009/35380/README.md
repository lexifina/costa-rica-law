# Decreto Ejecutivo 35380

Otorga a todos los integrantes de delegaciones participantes, por período de tiempo que duren las negociaciones todas las inmunidades que la Convención de Viena sobre Relaciones Diplomáticas y Convención de Nueva York sobre Misiones Especiales reconocen
