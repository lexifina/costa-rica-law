# Decreto Ejecutivo 35544

Concede asueto a empleados públicos de Adm. Central, con salvedades que establecen las leyes especiales, con motivo partido de futbol que sostendrá la Selección Nacional de Fútbol Sub 20 con selección Nacional de Rep. Federativa de Brasil
