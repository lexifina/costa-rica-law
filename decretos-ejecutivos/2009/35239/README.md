# Decreto Ejecutivo 35239

Promulga Acuerdo Embajada EEUU y nota Ministerio Relaciones Exteriores y Culto en el que se formalizó Acuerdo para compartir información para localización, identificación, rastreo e interceptación de aeronaves civiles en espacio aéreo República Costa Rica
