# Decreto Ejecutivo 35467

Promulga teniendo como vigente para los efectos internos y externos la Carta de Entendimiento sobre la Iniciativa Mérida suscrita entre el Gobierno de la República de Costa Rica y el Gobierno de los Estados Unidos de América
