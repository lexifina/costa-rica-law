# Decreto Ejecutivo 35110

Reforma al Reglamento de las Empresas y Actividades Turísticas, para fijar en tres tenedores para las empresas de restaurantes y en tres copas para los centros de diversión nocturna, para optar por el régimen voluntario de de la declaratoria turística
