# Decreto Ejecutivo 35477

Declara de interés público las acciones y la ejecución de obras tendientes a la reubicación, construcción y/o reconstrucción de infraestructura de viviendas y/o edificaciones, entrega de materiales a poblados afectados por el terremoto del 8 enero de 2009
