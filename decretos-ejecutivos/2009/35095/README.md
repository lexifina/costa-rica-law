# Decreto Ejecutivo 35095

Convoca con carácter de transitorio a la Reserva de las Fuerzas de Policía, para atender y coordinar con las autoridades de policia, las labores de vigilancia y protección de la seguridad pública, de sus ciudadanos y sus bienes
