# Decreto Ejecutivo 1043

Concede Incentivos Fiscales al señor Héctor Meléndez J. para su planta industrial destinada a la manufactura de vestidos de mujer y de niño, por equiparación de acuerdo con el T 1 del Convenio Centroamericano de Incentivos Fiscales D. I
