# Decreto Ejecutivo 1027

Concede Incentivos Fiscales al señor Fernando Sánchez Ruphuy, para su planta industrial destinada a la cocinas eléctricas y cocinas para combustibles líquidos, por equiparación de acuerdo con el A 9 del Convenio Centroamericano de Incentivos Fiscales D. I
