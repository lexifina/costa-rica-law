# Decreto Ejecutivo 1042

Desgloce decontenido económico de aumentos anuales a los servidores protegidos por el Estatuto de Servicio Civil(personal administrativo del MEP)(“Listin Administrativo”) a la L 4566 y las reasignaciones de puestos efectuados antes del 1° de junio de 1969
