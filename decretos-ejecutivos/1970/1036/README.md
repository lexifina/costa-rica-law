# Decreto Ejecutivo 1036

Concede beneficios a "Ticatejidos Sociedad Anónima" para su planta industrial destinada a la manufactura de tejidos de punto de media o ganchillo de fibras textiles naturales o sintéticas, puras o mezcladas entre sí y el acabado de esos tejidos
