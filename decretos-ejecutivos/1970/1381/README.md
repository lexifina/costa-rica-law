# Decreto Ejecutivo 1381

Destaca funcionarios con el respectivo equipo y mobiliario de la Sección Docente de la Dirección General Servicio Civil, las Oficinas Centrales del Ministerio Educación Pública con las funciones y atribuciones que actualmente le corresponden
