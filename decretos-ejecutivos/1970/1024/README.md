# Decreto Ejecutivo 1024

Concede Incentivos Fiscales a los señores Samuel Lustig, Alvaro Sancho y Samuel Guzowski para su planta industrial destinada a la manufactura de tubería plástica, por equiparación de acuerdo con el Convenio Centroamericano de Incentivos Fiscales D. I
