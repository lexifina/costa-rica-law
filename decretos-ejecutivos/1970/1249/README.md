# Decreto Ejecutivo 1249

Concede a Laboratorios Farinelli Limitada para su planta industrial, destinada a la manufactura de cosméticos, por equiparación de acuerdo con el Transitorio Primero del Convenio Centroamericano de Incentivos Fiscales al Desarrollo Industrial
