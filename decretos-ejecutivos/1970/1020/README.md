# Decreto Ejecutivo 1020

Concede al señor Héctor Ferlini Barrantes, para su planta industrial destinada a la manufactura de refrigeradoras comerciales y congeladores, por equiparación de acuerdo con el transitorio primero del Convenio Centroamericano de Incentivos Fiscales D. I.
