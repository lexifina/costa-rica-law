# Decreto Ejecutivo 1021

Concede Incentivos Fiscales al señor Akmed Zafer Nashashibi, para su planta industrial destinada a la manufactura de pesticidas para la agricultura en general, por equiparación de acuerdo con el T 1 del Convenio Centroamericano de Incentivos Fiscales D. I
