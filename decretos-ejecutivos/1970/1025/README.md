# Decreto Ejecutivo 1025

Concede Incentivos Fiscales al señor Israel Nowalski Berman para su planta industrial destinada a la manufactura de tejidos de punto de fibras natural., artif. o sint por equiparación de acuerdo con el Convenio Centroamericano de Incentivos Fiscales D. I
