# Decreto Ejecutivo 1248

Concede incentivos fiscales a Laboratorios Romogo Limitada para su planta industrial destinada a la manufactura de cosméticos, por equiparación de acuerdo con el Transitorio Primero del Convenio Centroamericano de Incentivos Fiscales al Desarrollo Industr
