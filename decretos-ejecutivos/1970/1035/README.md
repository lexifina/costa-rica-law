# Decreto Ejecutivo 1035

Reforma decreto ejecutivo que concede beneficios a "Carlos Luis Odio Limitada" para su planta industrial destinada a la manufactura de envases de metal para cierre hermético al vacío (automático) y con tapa removible

- Fecha: 1970-06-10
