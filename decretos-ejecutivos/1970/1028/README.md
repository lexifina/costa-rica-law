# Decreto Ejecutivo 1028

Concede Incentivos Fiscales al señor Moisés Natan Rochwerger, para su planta industrial destinada a la manufactura de carteras para mujer y para niño, bultos.. por equiparación de acuerdo con el T 1 del Convenio Centroamericano de Incentivos Fiscales D. I
