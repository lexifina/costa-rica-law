# Decreto Ejecutivo 86

La Asamblea Constituyente declara nulo atentario y criminal lo practicado por Lic. Braulio Carrillo, en ejercicio de Poderes Ejecutivo, Legislativo y Constituyente, indicando cuales de sus disposiciones deben continuar rigiendo provisionalmente
