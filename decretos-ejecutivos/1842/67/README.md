# Decreto Ejecutivo 67

El Gobierno Provisorio deroga el Decreto de 8 de Marzo de 1841, restablece las garantías consignadas en la Constitución de 1825, y dicta otras disposicioners provisionales, mientras la Asamblea Constituyente

- Número: 67
- Fecha: 1842-06-06
- Ente emisor: Jefe de Estado
