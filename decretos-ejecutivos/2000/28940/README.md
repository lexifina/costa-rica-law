# Decreto Ejecutivo 28940

Se amplía el Decreto Ejecutivo Nº 26515-J autorizando al Registro Nacional a celebrar convenios de desconcentración de servicios con empresas servicio que se constituyen en sociedades anónimas, cuyo capital sea 100% del estado
