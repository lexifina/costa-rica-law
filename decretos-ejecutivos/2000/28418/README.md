# Decreto Ejecutivo 28418

Crea las Gerencias Sectoriales Regionales como Enlace entre el Ministro de Agricultura y Ganadería en su Calidad de Rector del Sector Agropecuario y los Directores Regionales y Sectoriales de todas las Instituciones que conforman el Sector Agropecuario.
