# Decreto Ejecutivo 28765

Autoriza Aumento Salarial Servidores Públicos ( II Semestre 2000 )de 4 600 colones. Rige a partir del 1° Julio del 2000, siendo pagadoen la segunda quincena del mes de Julio.
