# Decreto Ejecutivo 6732

Expropia terreno de la Municipalidad de La Unión para la operación de una planta eléctrica y la construcción de un Centro de Enseñanza para operadores de planta y Subestaciones eléctricas del Instituto Costarricense de Electricidad
