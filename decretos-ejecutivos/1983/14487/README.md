# Decreto Ejecutivo 14487

Reforma Concede a artesanos y pequeños industriales la exoneración del 100% de los derechos arancelarios para la importación de maquinaria, herramientas, equipo y materias primas necesarios para la utilización en sus talleres industriales o artesanales
