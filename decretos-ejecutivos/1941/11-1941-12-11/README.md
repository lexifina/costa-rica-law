# Decreto Ejecutivo 11-1941-12-11

Todos los costarricenses deben contribuir en la medida de sus facultades, a la defensa del Estado durante el conflicto con Alemania, Italia y Japón y prestar a las autoridades constituidas los auxilios para que esos fines les sean requeridos
