# Decreto Ejecutivo 15449

Los licores nacionales y extranjeros que se ofrezca al público para consumo nacional, deberá llevar en su respectiva etiqueta de manera visible la leyenda: "el tomar licor es nocivo para la salud” (Etiquetado de Licores)
