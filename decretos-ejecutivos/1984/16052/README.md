# Decreto Ejecutivo 16052

Cambia nombre de Reserva Indígena Guaymí de Abrojos, Montezuma a Guaymí de Abrojo de Montezuma, de Cabécar de Tayni, Estrella a Cabécar de Tayni e indica que el nombre correcto es Reserva Indígena Guaymi de Conteburica
