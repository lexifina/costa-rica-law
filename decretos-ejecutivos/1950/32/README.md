# Decreto Ejecutivo 32

Cambia nombre del distrito 3° del cantón de Moravia, el de “Guayabal o La Trinidad” por el solo nombre de “La Trinidad”

- Tipo: Decreto Ejecutivo
- Número: 32
- Fecha: 1950-03-24
