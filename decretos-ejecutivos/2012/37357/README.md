# Decreto Ejecutivo 37357

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste del 0.38%

- Número: 37357
- Fecha: 2012-09-06
