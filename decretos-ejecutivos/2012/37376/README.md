# Decreto Ejecutivo 37376

Declara de interés público y nacional la Presidencia Pro Témpore que ostentará Costa Rica en Sistema Integración Centroamericana (SICA) celebración Reunión Ordinaria de Jefes de Estado y Gobierno del SICA, Cumbres Extraordinarias del SICA
