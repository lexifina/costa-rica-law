# Decreto Ejecutivo 37367

Declara el 7 de abril de cada año "Día de la Meteorología Nacional" y Declara de interés público las actividades de celebración del 125 aniversario de creación del Instituto Meteorológico Nacional y Creación del Premio Nacional "Dr Henri Pittier Dormond"
