# Decreto Ejecutivo 37256

Deroga varios decretos ejecutivos del MEIC y MEC referentes a diferente productos del mercado (azúcar blanco, almidón maíz, yuca, gelatina, clavos, losetas barro, tubo accesorios instalaciones eléctricas, bebidas alcohólicas, calidad jamón crudo, etc)
