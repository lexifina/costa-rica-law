Artículo 53.- Hielo. Cuando el hielo se elabora en el establecimiento debe ser fabricado a partir de agua potable, caso contrario provenir de una fábrica autorizada. Se debe mantener en recipientes cerrados, limpios y desinfectados. El hielo no debe manipularse directamente con las manos, se hará con pinzas, cucharas o similares. El hielo utilizado en el enfriamiento de botellas, copas ú otros debe ser de agua potable y este no podrá utilizarse para consumo humano.
