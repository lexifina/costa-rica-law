# Decreto Ejecutivo 22164

La Dirección General de Tributación Directa transferirá a la base de datos del Registro Único Inmobiliario (RUI) la información actualizada del Registro de Contribuyentes, Registro de Valores Inmuebles, Registro de Construcciones de Alto Valor y del Sistema Integral Tributario (SIT)
