Artículo 309.-Las credenciales de las licencias serán del color que a continuación se indican:
b) Para piloto comercial de avión color azul claro;
a) Para piloto privado de avión color pardo claro;
c) Para piloto comercial de primera clase de avión color azul oscuro;
d) Para piloto de transporte de línea aérea de avión color verde oscuro;
e) Para navegante color rojo;
f) Para radioperador de a bordo color anaranjado:
g) Para mecánico de a bordo color pardo; •
h) Para piloto de planeador color rosado;
i) Para piloto de globo libre color violeta;
j) Para piloto privado de helicóptero color gris claro;
k) Para piloto comercial de helicóptero color gris oscuro;
l) Para piloto de transporte de línea aérea de helicóptero dos franjas, de color gris oscuro sobre fondo blanco;
m) Para mecánico de mantenimiento de aeronaves, Tipo 1 y II color marrón;
n) Para mecánico de radio de aeronaves dos franjas de color marrón sobre fondo blanco;
o) Para controlador de tránsito aéreo color amarillo;
p) Para encargado de operaciones de vuelo color verde claro;
q) Para operador de estación aeronáutica dos franjas anaranjadas sobre fondo blanco; y
r) Para instructor teórico terrestre color blanco.
(Así corrida su numeración mediante artículo 1° del decreto ejecutivo N° 23079 del 21 de marzo de 1994, que lo traspasó del antiguo artículo 308 al 309)
