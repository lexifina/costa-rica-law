Distancias Mínimas de Separación de Calles de Rodaje
Artículo 55.-La distancia entre cualquier punto del borde de una calle de rodaje y el borde de una pista no debe ser menor que:
150 m. Para vuelo por instrumentos y 75 m., para otras pistas para la letra de clasificación técnica A;
150 m. Para vuelo por instrumentos y 73 m., para otras pistas para las letras de clasificación técnica B o C;
36 m. Para la letra de clasificación técnica D ;
29 m. Para la letra de clasificación técnica E ; y
25 m. Para la letra de clasificación técnica F.
