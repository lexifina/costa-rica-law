Artículo 103.-Los obstáculos cuya proyección en cualquier plano vertical tengan ambas dimensiones inferiores a 1.50 m., se colocarán con un solo color llamativo.
Se empleará el color anaranjado o el rojo, excepto cuando dichos colores se confundan con el fondo. Con algunos fondos puede que resulte necesario usar un color que no sea anaranjado ni rojo, para obtener suficiente contraste.
