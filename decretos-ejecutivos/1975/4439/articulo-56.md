Artículo 56.-La distancia entre cualquier punto del borde de una calle de rodaje y el borde de otra calle de rodaje, no debe ser menor que:
62 m. Para la letra de clasificación técnica A;
52 m. Para la letra de clasificación técnica B;
43 m. Para la letra de clasificación técnica C;
27 m. Para la letra de clasificación técnica D;
23 m. Para la letra de clasificación técnica E; y
20 m. Para la letra de clasificación técnica F.
