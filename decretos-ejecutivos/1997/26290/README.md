# Decreto Ejecutivo 26290

Declara estado de necesidad y urgencia por calamidad pública la situación provocada por el fenómeno El Niño Oscilación del Sur (ENOS), en toda la Vertiente Pacífica, incluyendo el área de cobertura marítimo del sector pesquero
