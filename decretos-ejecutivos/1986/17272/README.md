# Decreto Ejecutivo 17272

Prohíbe el empleo de redes de arrastre en aguas territoriales del mar Atlántico, durante el período comprendido entre el primer día del mes de octubre y el último día del mes de enero de cada año para la captura Langosta con Fines Comerciales
