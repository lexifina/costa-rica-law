# Decreto Ejecutivo 16925

Autoriza al Departamento de Vida Silvestre a otorgar permisos a las personas de escasos recursos que habitan en el citado Refugio, para que colecten y comercien aquellos peces que queden atrapados en las lagunetas que se forman aisladas del caño principal
