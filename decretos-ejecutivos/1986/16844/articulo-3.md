Artículo 3°—La maquinaria agrícola exenta será la siguiente: máquinas sembradoras; arados y rastras de todo tipo; equipo para procesamiento de heno; equipo para arroz inundado; máquinas eólicas (molinos de viento); equipo para riego; bombas manuales, con o sin motor, para fumigación agrícola; bombas de agua sumergibles para uso en proyectos de riego y abrevaderos; chapeadoras y máquinas picadoras de pasto; equipos para ordeño automático y de enfriamiento para lecherías; palas, picos, machetes, macanas y demás herramientas menores de uso agropecuario.
El Poder Ejecutivo, mediante Decreto Ejecutivo, podrá variar la lista contenida en este artículo.
