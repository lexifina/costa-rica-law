# Decreto Ejecutivo 18346

Prohibir el registro, importación, tránsito, almacenamiento, venta y uso de los insecticidas, Aldrín, Toxafeno, Clordecone, Clordimeform, del fungicida nematicida Dibromocloropropano, del nematicida Etilendibromuro, y los herbicidas Dinoseb y Nitrofén
