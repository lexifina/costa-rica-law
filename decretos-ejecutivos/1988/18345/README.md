# Decreto Ejecutivo 18345

Prohibe el registro, importación, venta, uso agrícola, veterinario y como medicamento, del insecticida DDT y de aquellos productos que contengan DDT

- Tipo: Decreto Ejecutivo
- Número: 18345
- Fecha: 1988-07-15
- Ente emisor: Poder Ejecutivo
