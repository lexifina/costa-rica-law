# Decreto Ejecutivo 27192

Declara Estado Emergencia, necesidad y urgencia, por calamidad pública y fuerza mayor la situación provocada por las fuerzas naturales y el efecto de las torrenciales lluvias en Cachí Calle Boza Roble y Paraíso Cartago
