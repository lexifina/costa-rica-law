# Decreto Ejecutivo 27773

Prohíbe registro, formulación, fabricación, importación, exportación, tránsito, depósito, almacenamiento, venta y uso agrícola, veterinario productos que contengan DDT, lindano y sus isómeros, pentaclorofenol y los microcontaminantes
