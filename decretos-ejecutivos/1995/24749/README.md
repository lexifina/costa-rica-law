# Decreto Ejecutivo 24749

Deroga anterior Programa de Formación Integral para Mujeres Jefas de Hogar "ASIGNACION FAMILIAR TEMPORAL" y establece nuevo Programa de Formación Integral para Mujeres Jefas de Hogar "ASIGNACION FAMILIAR TEMPORAL"
