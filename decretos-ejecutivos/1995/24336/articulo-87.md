Artículo 87.-- Rige a partir de su publicación.
Transitorio Primero
Se darán sesenta días calendario, a partir de la publicación de este
Reglamento para que las Ferias del Agricultor establecidas y oficinas
autorizadas para la entrega de carnés, se ajusten a las disposiciones de
este reglamento.
Transitorio Segundo
Todas las autorizaciones otorgadas con anterioridad a la
promulgación del presente Reglamento, se mantendrán vigentes.
