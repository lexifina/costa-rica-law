# Decreto Ejecutivo 24182

Autoriza a AyA para que incluya dentro de sus estructuras tarifarias generales fondos para hacer frente a obligaciones que asuma como consecuencia transferencias donaciones préstamos y otras inversiones para desarrollar Programa de Construcción y Mejoras
