# Decreto Ejecutivo 24856

Declara de interés nacional para el desarrollo sostenible y la lucha a la pobreza, al PROGRAMA DE DESARROLLO RURAL INTEGRADO OSA-GOLFITO (FASE II) ALA 93/19 y Crea Comité Coordinador para dar el apoyo necesario al Programa Osa-Golfito Fase II, ALA 93/19
