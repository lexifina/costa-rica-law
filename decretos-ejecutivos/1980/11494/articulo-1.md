Artículo 1º.- Se amplíe la zona portuaria reservada, creada por la
ley número 5582 de 11 de octubre de 1974, y se define como tal, el área
comprendida dentro de los siguientes límites:
"A partir de la intersección de eje horizontal número 214 con la
costa, se sigue sobre el eje horizontal número 214 con rumbo Este hasta
interceptar el eje vertical número 463. A partir de este punto se sigue
sobre el eje vertical número 463, hacia el Sur hasta interceptar el río
Jesús María, a partir de este punto se sigue sobre la línea centro del
río Jesús María hasta interceptar el eje vertical número 461. A partir
de esa intersección se sigue sobre el eje número 461 hacia el Sur hasta
interceptar el eje horizontal número 207. A partir de esa intersección
se sigue sobre el eje número 207 hacia el Oeste hasta llegar a un punto
ubicado a una distancia de 200 metros de la costa. Luego se sigue sobre
una línea que bordea a la costa a 200 metros de distancia hasta
interceptar el eje horizontal número 209. A partir de ese punto se sigue
sobre el eje número 209 hasta interceptar la costa".
