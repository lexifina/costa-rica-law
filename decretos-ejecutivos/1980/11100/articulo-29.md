Artículo 29.- Son características de las prendas del uniforme:
a) El quepis de color azul marino, confeccionado en tela de gabardina o similar, con visera color negro, con barbijo negro o dorado, según jerarquía; el quepis podrá se cubierto con un plato accesorio plástico para lluvia o distintivo de servicio. En el quepis se portará el escudo nacional de Costa Rica en color dorado para oficiales y plateado para suboficiales y rasos.
b) La chaqueta de tela color azul marino o de vinílico color negro.
c) La camiseta de color celeste, con hombreras y bolsillos, de tela resistente. Esta prenda tendrá magas cortas o largas, según se disponga por clima.
d) La corbata de tela color negra o azul marino oscuro.
e) El pantalón de color azul marino, confeccionado en tela de gabardina o similar.
f) El pantalón a media pierna (breech), de color azul marino, confeccionado en tela de gabardina o similar, para uso de motociclistas.
g) El impermeable o capa de nailon doble, conjunto de dos piezas, jaquet y pantalón de color azul, para uso de los motociclistas.
h) La capa vinílica de color azul, para el personal de a pie.
i) Las botas de cuero color negro, decaña alta, para uso del personal motociclista.
j) El botón negro de tipo común, para uso del personal de a pie.
k) La faja blanca o azul para uso de todo el personal.
l) La cadena plateada y silbato de trino de metal cromado.
ll) El estuche vinílico blanco o negro, para guarda de equipo y elementos.
m) La cinta métrica de metal de tres metros.
n) El equipo especial que se determine, según funciones técnicas o específicas.
