# Decreto Ejecutivo 12023

Traspasa las funciones del programa 06-049: Servicios de Archivo Nacional del título 06 Ministerio de Gobernación y Policía, al título 17 Ministerio de Cultura Juventud y Deportes, las cuales quedarán adscritas a la Dirección General de Cultura
