ARTÍCULO 4.-Para los efectos de la Ley de Agroqímicos y Fodea se entender como maquinaria y equipo los utilizados en las actividades agrícolas, pecuarias, apícolas, acuicolas, as¡ como en las actividades que realizan las empresas de servicios en la agricultura mecanizada; a saber: máquinas sembradoras y abonadoras; cosechadoras de granos, de caña y forrajes, algodón y otros productos agrícolas tales como raíces, tubérculos y frutales; tractores agrícolas que reúnan las siguientes características:
a) Ancho de trocha ajustable.
b) Sistema de levante hidráulico trasero o delantero, con enganche de tres o dos puntos para el montaje de implementos agrícolas y sistemas hidráulicos para control remoto.
c) Toma de fuerza trasera o delantera para poner en acción distintos implementos;
d) Barra de tiro para el arrastre de implementos y carretes agrícolas y/o sistema de enganche (fijo o de levante autom tico) para jalar; cultivadores, subsoladores, arados y rastras de todo tipo, equipo para arroz inundado; máquinas eólicas (molinos de viento); equipo para riego, equipo para fumigación, bombas pulverizadoras) máquinas con o sin motor para fumigación, atomización y espolvoreo de agroquímicos exclusivamente; bomba de agua sumergibles para uso en proyectos de riego y abrevaderos; chapeadoras y máquinas picadoras de pasto; equipo para ordeño automático y de enfriamiento para lechería, instrumentos y equipo para inseminación artificial tales como: pistolas, guantes, termos de envases y cortadoras de pajillas, equipo quirúrgico para transferencia de embriones, y afines; jeringas de uso veterinario, agujas, equipos para prácticas de reproducción; detectores de mastitis; equipos para henificación (segadoras, acondicionadores, rastrillos, acordanadores y empacadoras o enfardadoras); cargadores de caña, carretas para transporte de uso agrícola de uno o dos ejes; motoazadas, cauterizador eléctrico para cuernos, envases cilindros con cierre herm‚tico para transporte de leche, equipo para el manejo de animales tales como: narigueras, argollas de nariz, frenos, chuzos, bozales, mangas, inmovilizadores: dosificadores orales, cauterizadores, tatuadoras, descolmilladores, dosificadores orales, cauterizadores, machetes, macanas, as¡ como dem s herramientas menores del mismo uso; implementos y equipos para la actividad apícola: ahumadores, esp tulas, velas, cepillos para abejas, guantes, overoles especiales, excluidores para abejas reinas, alimentadores de diferentes tipos y demás implementos menores, extractores para miel de abejas, estampadoras equipos de filtración de miel, refundidores de cera y equipo menor para esta actividad; artes de pesca para la acuicultura; incubadoras, comedores, bebederos, jaulas para la avicultura y jaulas de parición para la porcicultura.
