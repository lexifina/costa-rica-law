# Decreto Ejecutivo 17698

Prohibe el registro, importación, venta y uso agrícola, veterinario y como medicamente, del insecticida DDT y de aquellos productos que contengan DDT

- Tipo: Decreto Ejecutivo
- Número: 17698
- Fecha: 1987-08-05
