# Decreto Ejecutivo 33470

Autoriza la ruta que seguirá el cable submarino de fibra óptica denominado PAN AMERICAN CROSSING (PAC) COSTA RICA EXTENSIÓN (PAC-CR) de conformidad con el Contrato suscrito entre el ICE, RACSA y Global Crossing Costa Rica S.R.L.
