# Decreto Ejecutivo 33362

Declara de interés público y nacional, las actividades que llevarán a cabo el Ministerio de Salud y la Caja Costarricense de Seguro Social, con motivo de la celebración de una jornada de lucha contra el mosquito transmisor del dengue
