# Decreto Ejecutivo 32903

La Autoridad Presupuestaria considerará la solicitud de creación de plazas presentada por Ministerio de Ciencia, Tecnología y Telecomunicaciones, Ministerio de Planificación Nacional y Política Económica y Instituto de Desarrollo Rural
