# Decreto Ejecutivo 32998

La Autoridad Presupuestaria considerará solicitud del INS, de acuerdo con los requerimientos del área de salud de ese Instituto, con el fin de cumplir con las normas establecidas en el Reglamento para la Habilitación de Establecimientos de Salud y Afines
