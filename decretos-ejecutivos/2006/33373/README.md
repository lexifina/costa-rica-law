# Decreto Ejecutivo 33373

Declara estado de emergencia nacional la situación provocada por fenómeno meteorológico que generó fuerte actividad lluviosa y ocasionó serias inundaciones y deslizamientos cantones de Desamparados, Aserrí, San Ramón, Palmares y el cantón de Alfaro Ruiz
