# Decreto Ejecutivo 33389

Autoriza la importación de treinta mil toneladas métricas, de maíz blanco (30000 TM), con una tarifa de cero por ciento (0%) de Derechos Arancelarios a la Importación

- Fecha: 2006-09-26
