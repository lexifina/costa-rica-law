# Decreto Ejecutivo 33357

Deroga la Comisión Técnica de Trabajo MAG-MINAE-RECOPE-LAICA y la Comisión Técnica de trabajo del Estudio del Biodiesel. Crea la Comisión Nacional de Biocombustibles.
