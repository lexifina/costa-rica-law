# Decreto Ejecutivo 33108

Declara Estrategia Nacional para el Manejo del Fuego en Costa Rica 2006-2010 y Plan Nacional del Manejo del Fuego 2006-2010 como instrumentos oficiales. Ratifica Comisión Nacional sobre Incendios Forestales (CONIFOR) como instancia adscrita al MINAE
