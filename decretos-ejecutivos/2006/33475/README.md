# Decreto Ejecutivo 33475

Deroga decreto que Ordena a la Notaría del Estado el traspaso de las fincas propiedad del Estado inscritas a los Folios Reales, partido de Puntarenas, N° 137113-000, 137111-000 y 1371112, a favor del Instituto Costarricense de Turismo
