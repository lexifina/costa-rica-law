# Decreto Ejecutivo 33352

La Autoridad Presupuestaria considerará las solicitudes de creación de plazas presentadas por el ICE, ICT, Junta de Desarrollo Regional Zona Sur, Patronato Nacional de Ciegos y Comisión Nacional de Emergencias y Prevención del Riesgo
