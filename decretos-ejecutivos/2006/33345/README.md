# Decreto Ejecutivo 33345

Declara de interés público y nacional, las actividades que llevará a cabo el Servicio de Dermatología y Alergología del Hospital México, con motivo de celebración del "Primer Simposio Nacional de Dermatología Tropical Clínico, Laboratorio y Diagnóstico"
