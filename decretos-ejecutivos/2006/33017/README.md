# Decreto Ejecutivo 33017

La Autoridad Presupuestaria considera solicitud del Ministerio de Justicia y Gracia, referente a que el Patronato de Construcciones Instalaciones y Adquisición de Bienes cuente con recurso humano mínimo indispensable para el Sistema Penitenciario Nacional
