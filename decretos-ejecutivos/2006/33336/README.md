# Decreto Ejecutivo 33336

Declara de interés público y nacional, las actividades que llevará a cabo la Asociación Costarricense para el Estudio de la Obesidad, con motivo de la celebración del I Congreso Costarricense de Obesidad y Síndrome Metabólico
