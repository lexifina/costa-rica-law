# Decreto Ejecutivo 33521

Autoriza Importación como desabasto adicional al volumen autorizado de de sesenta y ocho mil ochenta y ocho toneladas métricas de arroz en granza (68.088 T.M.), con una tarifa de cero por ciento (0%)
