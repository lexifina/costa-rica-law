# Decreto Ejecutivo 33466

Publica Resolución Nº 178-2006 (COMIECO-XXXIX) Aprueba modificaciones al Arancel Centroamericano de Importación, el cual forma parte integrante del Anexo “A” del Convenio sobre el Régimen Arancelario y Aduanero Centroamericano
