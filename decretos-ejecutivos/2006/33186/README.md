# Decreto Ejecutivo 33186

Promulga teniendo como vigente para todos los efectos internos y externos el Acuerdo del cese del Convenio Comercial entre el Gobierno de la República de Costa Rica y el Gobierno de Rumania, bajo la modalidad de canje de notas
