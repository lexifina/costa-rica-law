# Decreto Ejecutivo 33358

Promulga teniendo como vigente para los efectos interno y externos, el Acuerdo entre el Gobierno de la República de Costa Rica y el Gobierno del Reino de Tailandia sobre exención mutua de visas para portadores diplomáticos y oficiales (servicio)
