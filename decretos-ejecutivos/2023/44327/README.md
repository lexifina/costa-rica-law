# Decreto Ejecutivo 44327

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste de cero coma cero nueve por ciento (0,09%)

- Número: 44327
- Fecha: 2023-12-18
- Ente emisor: Poder Ejecutivo
