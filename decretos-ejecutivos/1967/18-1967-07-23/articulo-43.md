Artículo 43.-Impuestos de consumo ad valórem. Los impuestos de consumo que gravan: licuadoras, radios, consolas y tocadiscos; cosméticos, perfumes, lociones y extractos, se deben calcular tomando como base sus precios de venta determinados en la etapa manufacturera. Los productores e importadores obligados a estos impuestos deben inscribirse en el Registro, independientemente del monto total de sus ventas. Los productores deben liquidarlos sobre el total de las ventas que efectúen, incluso las que realicen a responsables, salvo que se trate de exportaciones efectuadas en las condiciones establecidas en el artículo 19, párrafo segundo, de este Reglamento.
La liquidación y pago por las ventas realizadas en el mercado interno, se debe hacer mediante declaración jurada dentro de los plazos que indica el artículo 7° de la ley. En el caso de importaciones,. la liquidación y pago se debe hacer previo al desalmacenaje en las Aduanas, aun cuando los importadores sean responsables, sobre la base de adicionar al valor CIF, Aduana de Costa Rica, los derechos de importación y los demás gastos que figuren en la póliza correspondiente y que efectivamente se hayan pagado; los interesados deben probar el pago del impuesto previamente al desalmacenaje.
Se consideran cosméticos, entre otros, los siguientes productos: aceites para la piel; aceites para el cutis; Agua de Quina (para el cabello); antisépticos para enjuagar la boca; Bayrum; brillantina; coloretes faciales; colores para tocador, crema Dagelle (para el cutis); cremas para el tocador; cremas protectoras; champúes para el cabello; depilatorios; esmaltes para uñas; fijadores para el cabello; glicerina perfumada; lápices para cejas; lápices para labios, leches cutáneas; linimentos para el cabello; loción para el cabello; lociones para permanente; "pancake" para el cutis; pinturas para cejas; pinturas para labios; pinturas para pestañas; pinturas para el pelo; polvos de talco; polvos para tocador, comprimidos o no; pomadas cosméticas; pomadas para el pelo; pomadas para el bigote; pomadas para el cabello; pomadas para la barba; preparados para manicure; preparados para quitar el esmalte de uñas; preparados para permanentes; preparaciones protectoras contra el sol; preparaciones para pedicuros; sales de lavanda; sales perfumadas para el baño; talco boratado perfumado; talco de venecia; talco purificado; tintes para el cabello; tinturas para el cabello; tónicos para el cabello; tónicos para el cutis vaselina perfumada; vigorizador para el cabello; vinagre dentífrico. No se consideran cosméticos, los siguientes productos: aceites para niños talcos para niños; cremas para niños; jabones de tocador; cremas de afeitar y desodorantes.
