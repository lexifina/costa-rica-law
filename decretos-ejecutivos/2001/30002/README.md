# Decreto Ejecutivo 30002

Oficializa con caracter de obligatorias las "Normas de Costa rica para la Habilitación de Establecimientos con Internamiento en Medicina y Cirugía General y/o por Especialidades Médicas y Quirúrgicas con más de 20 camas".
