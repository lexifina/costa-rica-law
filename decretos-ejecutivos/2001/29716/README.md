# Decreto Ejecutivo 29716

Determina correspondencia de los estudios en la Escuela Vista del Monte (Mount View School) de Guachipelín de Escazú con el ciclo Materno infantil interactivo II, ciclo de transición de la Educación Prescolar y otros con el del Estado.
