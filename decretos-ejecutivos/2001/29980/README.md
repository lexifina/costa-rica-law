# Decreto Ejecutivo 29980

Autoriza al Poder Ejecutivo para qu por Decreto elaborado por el Ministerio de Hacienda continúe realizando las modificaciones presupuestarias de la Ley de Presupuesto Ordinario Y Extraordinario para el ejercicio fiscal del año 2001
