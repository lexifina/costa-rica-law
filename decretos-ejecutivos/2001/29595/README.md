# Decreto Ejecutivo 29595

Establece una prohibición total a la extracción y comercialización de moluscos bivalvos en todo el país, hasta tanto los estudios técnicos y científicos demuestren que estos productos pueden ser aptos nuevamente para el consumo humano.
