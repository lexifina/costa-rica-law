# Decreto Ejecutivo 29614

Se deroga el Decreto Ejecutivo N° 29409- J- MOPT- MAG que autoriza al Registro Nacional para que inscriba terrenos propiedad del Estado a nombre del Instituto Costarricense de Pesca y Acuacultura. (INCOPESCA).
