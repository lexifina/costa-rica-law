# Decreto Ejecutivo 29456

Reglamento para la emisión de gafetes de identificación, para el ingreso de personas a las áreas restringuidas y para el acceso y permanencia de vehículos automotores y otros equipos de servicio en tierra, en las áreas de plataforma y rampa, Aeropuerto.
