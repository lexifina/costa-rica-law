# Decreto Ejecutivo 29474

Comunica a la Dirección General de Migración y Extranjería que el monto que se cobre por la emisión de pasaportes o salvoconductos sean incluidos en los recibos de cobro de derechos para la expedición de pasaportes utilizados por el Banco de Costa Rica
