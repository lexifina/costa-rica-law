# Decreto Ejecutivo 29940

Oficializa la aplicación obligatoria en establecimientos de salud públicos y privados de Normas para la Habilitación de Establecimientos con Internamiento en Medicina y Cirugía General y/o por Especialidades Médicas y Quirúrgicas.
