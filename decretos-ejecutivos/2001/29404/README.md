# Decreto Ejecutivo 29404

Exceptúa al Patronato Nacional de la Infancia de la Aplicación del Decreto que determina que La Autoridad Presupuestaria no considerará solicitudes para la Creación de Plazas durante el Periodo Presupuestario del 2001

- Número: 29404
