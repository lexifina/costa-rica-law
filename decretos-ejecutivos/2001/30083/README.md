# Decreto Ejecutivo 30083

Crea el Consejo Ministerial para la Inocuidad de Alimentos (CMIA) y la Comisión Intersectorial para la Inocuidad de Alimentos, como instancias consultivas, de análisis, deliberación y recomendación del Poder Ejecutivo.
