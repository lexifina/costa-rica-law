# Decreto Ejecutivo 30008

Determina correspondencia de los estudios que se realicen en el centro educativo IBINA, deTres Ríos, La Unión, Cartago, con el ciclo Materno Infantil Grupo Interactivo II y el Ciclo de Transición , con los del Sistema Educativo Estatal.
