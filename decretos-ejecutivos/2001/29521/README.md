# Decreto Ejecutivo 29521

Prorroga por seis meses más el plazo establecido para la vigencia del Decreto Ejecutivo N° 29081, Impuesto Selectivo de Consumo establecido sobre los Combustibles tomando en cuenta la Base Tributaria
