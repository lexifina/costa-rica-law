# Decreto Ejecutivo 29601

Exceptua a la Dirección General de Migración y Extranjería de la aplicación del artículo 1º del Decreto Ejecutivo La Autoridad presupuestaria no considerará solicitudes para la creación de plazas durante el periodo presupuestario del 2001.
