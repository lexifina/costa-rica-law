# Decreto Ejecutivo 30013

Deja sin efecto el nombramiento de la Señora Ana Cecilia Valería Pizarro, como representante de la Unión de Gobiernos Locales ante el Consejo Nacional de Desarrollo Comunal, y se nombra a la Señora Ligia Sancho Carvajal
