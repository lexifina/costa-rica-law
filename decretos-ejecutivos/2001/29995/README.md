# Decreto Ejecutivo 29995

Promulga teniéndolo como vigente, para todos los efectos internos y externos, el Acuerdo mediante Canje de Notas DM- DCI- 921-01, para la modificación de planes de estudio de la enseñanza básica y la enseñanza diversificada del Liceo Franco Costarricense
