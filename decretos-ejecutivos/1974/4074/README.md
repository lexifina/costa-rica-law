# Decreto Ejecutivo 4074

Confiere Plenos Poderes al Licdo. Oscar Arias Sánchez, para que en representación del Gobierno de Costa Rica firme el Contrato de Cooperación Técnica ATN/TS 1321-VA entre Oficina de Planificación y Política Económica y Banco Interamericano de Desarrollo
