Artículo 20.- Procesos de la Unidad de Planificación Institucional. Para brindar el servicio de forma eficiente como instancia asesora, la Unidad de Planificación Institucional cuenta con cuatro procesos de trabajo:
1. Proceso de Gestión de Planeamiento Estratégico;
2. Proceso de Gestión de Proyectos Especiales;
3. Proceso de Gestión y Calidad Institucional;
4. Proceso de Gestión de Planes y Presupuesto; y
5. Proceso de Gestión de Seguimiento y Evaluación.
