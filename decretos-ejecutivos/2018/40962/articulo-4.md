Artículo 4º—Mientras no se disponga de una red de referencia vertical actualizada, modelo de geoide, red gravimétrica y series de mediciones de datos mareográficos contemporáneas oficiales para Costa Rica asociado al “datum” geodésico horizontal CR-SIRGAS, el “datum” o nivel de referencia vertical o red de nivelación, seguirá siendo el tradicional, determinado por técnicas de topografía convencionales y las observaciones mareográficas tomadas para las épocas entre 1940 y 1960 correspondientes a la determinación del nivel de referencia con base en el nivel medio del mar.
