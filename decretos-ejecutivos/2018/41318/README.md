# Decreto Ejecutivo 41318

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste de cero coma treinta y nueve por ciento (0,39%)

- Tipo: Decreto Ejecutivo
- Número: 41318
- Fecha: 2018-09-17
- Ente emisor: Poder Ejecutivo
