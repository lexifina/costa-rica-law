# Decreto Ejecutivo 41195

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste de menos cero coma veintidós por ciento (-0,22%)

- Número: 41195
- Fecha: 2018-06-11
