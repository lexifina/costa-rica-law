# Decreto Ejecutivo 41393

Publica resolución N° 398-2018 (COMIECO-LXXXIII) 28/06/2018 aprueba adopción por parte República Panamá a partir de 01/01/2029 de reglas de origen específicas para grasas y aceites de anexo Regl Centroamericano sobre origen de mercancías
