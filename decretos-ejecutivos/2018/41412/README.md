# Decreto Ejecutivo 41412

Promulga acuerdo baja la modalidad de canje de notas con la República Federal de Alemania sobre establecimiento de una oficina local de la Deutsche Gesellschaft fur Internationale Zusammenarbeit (GIZ) GmbH
