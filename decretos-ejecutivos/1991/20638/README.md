# Decreto Ejecutivo 20638

Se acepta la renuncia del señor Victor Emilio Herrera Alfaro al cargo de Ministro de Seguridad Pública y se recarga en el señor Luis Fishman Zonzinski, Ministro de Gobernación y Policía, la cartera de Seguridad Pública
