# Decreto Ejecutivo 40838

Reforma Autoriza al Departamento de Exenciones de la Dirección General de Hacienda, para que realice mediante un Sistema de Información Electrónico denominado EXONET el trámite de las solicitudes de exención de tributos para los beneficiarios de incentivo
