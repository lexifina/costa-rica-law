# Decreto Ejecutivo 40692

Establece el Reconocimiento de las Reservas de Biosfera como territorios modelos para el desarrollo sostenible y el establecimiento de la estructura orgánica para su gestión y declaratoria de Día Nacional de las Reservas de Biosfera de Costa Rica
