# Decreto Ejecutivo 40561

Promulga teniéndolo como vigente el Acuerdo bajo la modalidad de Canje de Notas constituido entre Costa Rica y la República Federal de Alemania sobre el proyecto "Cambio climático y transporte en Costa Rica"
