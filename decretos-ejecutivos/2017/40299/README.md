# Decreto Ejecutivo 40299

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste de uno coma treinta y siete por ciento (1,37%)

- Tipo: Decreto Ejecutivo
- Número: 40299
- Fecha: 2017-03-07
- Ente emisor: Poder Ejecutivo
