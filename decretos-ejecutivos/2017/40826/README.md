# Decreto Ejecutivo 40826

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste de cero coma noventa y siente por ciento (0,97%)

- Número: 40826
- Fecha: 2017-12-07
- Ente emisor: Poder Ejecutivo
