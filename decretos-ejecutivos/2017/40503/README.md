# Decreto Ejecutivo 40503

Declara de interés público el Proyecto de Exploración y Evaluación de Aguas Subterráneas de la República de Costa Rica en el marco del Acuerdo suscrito entre el Servicio Geológico de los Estados Unidos de América y el Ministerio de Ambiente y Energía
