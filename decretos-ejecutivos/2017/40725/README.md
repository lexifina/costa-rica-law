# Decreto Ejecutivo 40725

Crea la Comisión Interinstitucional para la Gestión del Conocimiento y la Información sobre Biodiversidad (CIGECIB) y Declara de Interés Público de la Plataforma Informática para gestión de conocimiento e información nacional sobre la biodiverdiversidad
