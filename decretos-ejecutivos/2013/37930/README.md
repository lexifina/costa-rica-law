# Decreto Ejecutivo 37930

Establece hora de inicio de jornada laboral diara de Ministerios de Gobierno y sus Instituciones Adscritas cuyas dependencias se encuentren en cantones Central San José, Goicoechea, Montes de Oca, Curridabat, Escazú, Santa Ana, Alajuelita y Desamparados
