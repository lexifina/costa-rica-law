# Decreto Ejecutivo 37673

Reforma Regl. de Control Migratorio y Regl. de Extranjería y implementa por un lapso de 3 meses a partir del 17/06/2013 hasta 17/09/2013 período regularización migratoria para trabajadores de sectores agrícola, construcción y área del servicio doméstico
