# Decreto Ejecutivo 21326

Actualiza la lista de los gases medicinales y uniforma los colores y tipos de válvulas de empate de los cilíndros que contienen gases medicinales.

- Tipo: Decreto Ejecutivo
- Número: 21326
- Fecha: 1992-06-02
