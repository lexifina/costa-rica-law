Artículo 90.—Procedimientos técnicos para el manipuleo y proceso.
a) La temperatura a que se descongela la materia prima y el tiempo requerido.
b) El procedimiento utilizado para identificar lotes durante el proceso.
c) Combinación tiempo/temperatura a la cual se almacena el producto antes y después de cocinarse los productos.
d) Código utilizado para identificar producto terminado (si se utiliza).
e) Cualquier punto crítico que pueda afectar a la calidad del producto.
f) Gráficos registradores de tiempo/humedad.
