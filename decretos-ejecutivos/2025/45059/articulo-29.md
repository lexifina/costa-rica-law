Artículo 29.- Accesorios para calderas tipo C y D para generar vapor: Deben estar dotadas de los dispositivos siguientes:
1) Para el caso de calderas generadoras de vapor de agua:
a) Dos válvulas de seguridad para categoría C y una para las de categoría D.
b) Dos indicadores de nivel de agua para la categoría C y un indicador de nivel de agua para categoría D.
c) Dos controles del nivel del agua para las calderas de categoría C y de uno para las categorías D.
d) Dos manómetros para las calderas de categoría C y de uno para las categorías D.
e) Dos controles de presión para las calderas de categoría C y de uno para las categorías D.
f) De los sistemas de alimentación de agua, solicitados en este reglamento.
g) De las válvulas de entrada y salida solicitadas en este reglamento.
h) De aberturas de inspección, tanto en el lado del agua como en el lado del fuego.
2) Para el caso de calderas generadoras de vapor de fluidos térmicos:
a) Dos válvulas de seguridad para calderas categoría C y una para categoría D.
b) Discos de ruptura a la entrada de las válvulas de seguridad.
c) Tanque donde se depositen las descargas de las válvulas de seguridad.
d) Dos controles de presión.
e) Dos indicadores de nivel de agua para la categoría C y un indicador de nivel del fluido para categoría D.
f) Dos controles del nivel del fluido.
g) Un indicador de la temperatura del aceite.
h) Paro por alta temperatura de los gases en chimenea.
i) De las válvulas de entrada solicitadas en este Reglamento.
j) De aberturas de inspección, tanto en el lado del fluido como en el lado del fuego.
