# Decreto Ejecutivo 44920

Oficializa la "Norma para la habilitación de Centros de Atención de Bajo Umbral para la reducción de daño, dirigido a personas mayores de edad con consumo de sustancias psicotrópicas en situación de vulnerabilidad"
