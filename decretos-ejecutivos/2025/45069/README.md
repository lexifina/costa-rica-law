# Decreto Ejecutivo 45069

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre jabones de tocador, mediante un ajuste de menos uno coma veintidós por ciento (-1,22%)

- Número: 45069
- Fecha: 2025-06-17
