# Decreto Ejecutivo 45212

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre jabones de tocador, mediante un ajuste de menos cero coma sesenta y ocho por ciento (-0,68%)
