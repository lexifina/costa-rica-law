# Decreto Ejecutivo 45356

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre jabones de tocador, mediante un ajuste cero coma veinticinco por ciento (0,25%)

- Número: 45356
- Fecha: 2025-12-09
- Ente emisor: Poder Ejecutivo
