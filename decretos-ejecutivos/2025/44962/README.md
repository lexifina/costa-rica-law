# Decreto Ejecutivo 44962

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre jabones de tocador mediante un ajuste de uno coma treinta por ciento (1,30%)

- Número: 44962
- Fecha: 2025-03-07
