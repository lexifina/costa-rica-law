# Decreto Ejecutivo 1495

Confiere poderes al representante de CR ante la Organización de Estados Centroamericanos para que en representación del Gobierno de Costa Rica deposite el Instrumento Ratificado del Protocolo de Ingreso de la República de Panamá a Nuevos Órganos de ODECA
