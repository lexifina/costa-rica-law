# Decreto Ejecutivo 1462

Confiere poderes al Asesor del Ministerio de Relaciones Exteriores, para que en representación del Gobierno suscriba Ad eferéndum,convenio, acuerdos, instrumentos, actas y resoluciones en la Conferencia Internacional de Plenipotenciarios de Derecho Aéreo
