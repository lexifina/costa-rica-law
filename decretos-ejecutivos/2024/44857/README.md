# Decreto Ejecutivo 44857

Declara de interés público y nacional las acciones de mitigación de los riesgos, necesarias para mejorar las condiciones de seguridad, el desarrollo de infraestructura y el acceso a servicios esenciales en la Ruta Nacional 32
