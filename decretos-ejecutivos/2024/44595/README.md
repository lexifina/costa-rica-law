# Decreto Ejecutivo 44595

Publica Resolución Nº 484-2023 (COMIECO-CV) de fecha 05/12/2023, que aprobó aperturas arancelarias dentro del Arancel Centroamericano de Importación para papeles "bond'''' (excepto el "bond'''' registro) y "ledger", incluso mimeógrafo y fotocopia
