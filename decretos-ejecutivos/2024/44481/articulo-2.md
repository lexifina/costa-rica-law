Artículo 2-Abreviaturas. Se aplicarán las siguientes:
a) ABRE: Áreas Bajo Regímenes Especiales
b) DTA: División Territorial Administrativa
c) GNSS: Sistema Global de Navegación por Satélite / Global Navigation Sattelite System
d) IDECORI: Infraestructura de Datos Espaciales de Costa Rica
e) IGN: Instituto Geográfico Nacional
f) IGS: International GNSS Service / Servicio Internacional GNSS
g) LAND-Geo: Laboratorio de Análisis de Datos Geodinámicos
h) MGDN: Marco Geodésico Dinámico Nacional
i) OGC: Open Geoespatial Consortium / Consorcio Geoespacial Abierto
j) SIG: Sistema de Información Geográfica
k) SIGI: Sistema de Información Geográfica del IGN
l) SNIT: Sistema Nacional de Información Territorial
m) URL: Dirección web para la utilización de datos como un servicio bajo estándares del OGC.
n) ZMT: Zona Marítimo Terrestre
