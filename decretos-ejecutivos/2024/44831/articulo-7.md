Artículo 7.- Contraindicaciones relativas para Donación de Tejido Ocular:
a) Tratamientos actuales o previos:
i. Vacunación con microorganismos atenuado: se podrá utilizar el tejido en caso de contar con previo visto bueno del Banco de Ojos ante la consulta del caso.
ii. Tuberculosis: contraindicada si no ha recibido tratamiento. Se podrá utilizar el tejido si ha recibido tratamiento completo para tuberculosis y con seguimiento posterior.
iii. Sífilis: contraindicada si no ha recibido tratamiento. Se podrá utilizar el tejido si ha recibido tratamiento para sífilis y con seguimiento posterior.
iv. Sepsis de origen bacteriano por cepas de bacterias NO resistentes: se podrá extraer el tejido corneal siempre y cuando este tejido se procese y cultive en el banco (es necesaria la extracción de hemocultivos del donante).
b) Contraindicaciones oculares relativas:
i. Antecedente de cirugía refractiva: se podrá utilizar el tejido en caso de contar con previo visto bueno del Banco de Ojos, quienes valorarán el tipo de intervención y técnica utilizada.
ii. DMEK: se podrá utilizar el tejido en caso de contar con previo visto bueno del Banco de Ojos
iii. Pterigión: se podrá utilizar el tejido en aquellos casos que no se invada el eje visual.
