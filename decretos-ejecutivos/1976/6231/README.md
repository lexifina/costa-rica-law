# Decreto Ejecutivo 6231

Deja sin efecto el decreto ejecutivo N° 18 de 30/04/1968, única y exclusivamente para Licitación Pública que hará el Banco de Costa Rica, para el arrendamiento de los locales comerciales del primer piso y del primer sótano, de su nuevo edificio central
