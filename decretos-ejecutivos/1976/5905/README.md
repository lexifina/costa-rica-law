# Decreto Ejecutivo 5905

Declara Zona de Emergencia Nacional las áreas del territorio Nacional comprendidas en las demarcaciones de las Reservas Indígenas (Boruca - Térraba, Ujarrás - Salitre - Cabagra, China Kichá, Guatuso, Guaymi, Chirripó, Estrella, Talamanca)
