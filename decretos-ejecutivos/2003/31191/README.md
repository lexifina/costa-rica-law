# Decreto Ejecutivo 31191

Prorroga por seis meses el plazo de la Comisión de Evaluación y Diagnóstico de las Actividades Geológicas y Mineras de la Dirección de Geología y Minas para emitir el Informe ante el Jerarca Ministerial.
