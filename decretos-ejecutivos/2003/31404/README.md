# Decreto Ejecutivo 31404

Exonera los Vehículos con una Capacidad de Carga Máxima Prevista (carga útil) de 2 o más Toneladas, Ubicados en los incisos Arancelarios del Sistema Arancelario Centroamericano 8704.21.90 y 8704.31.90, del Impuesto Selectivo de Consumo.
