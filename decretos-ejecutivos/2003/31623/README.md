# Decreto Ejecutivo 31623

Autoriza al Ministerio de Agricultura y Ganadería para que continúe durante el año 2003 y hasta su finalización, con la ejecución de los recursos del Fondo de Asistencia Técnica, generados mediante el Convenio entre el Banco Central y el Banco Nacional
