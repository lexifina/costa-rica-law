# Decreto Ejecutivo 30948

Pone en vigencia Resolución que Reforma las reglas específicas de origen contenidas en el Anexo del Reglamento Centroamericano sobre el Origen de las Mercancías (Resolución Nº 100- 2002 (COMIECO-XXV)).
