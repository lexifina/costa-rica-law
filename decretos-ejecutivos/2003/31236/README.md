# Decreto Ejecutivo 31236

Pone en vigencia la Resolución N° 111-2003 (COMEICO-XXVII), Aprueba para su aplicación en Honduras y Nicaragua la aplicación de Mecanismos de Solución de Conroversias Comerciales entre Centroamérica, la utilización de Listas de Árbitros.
