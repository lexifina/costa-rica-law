# Decreto Ejecutivo 28098

Medidas para cumplimiento de artículo 3 de Ley N° 7722 “Sujeción Instituciones estatales al pago de impuesto sobre renta” para que los recursos provenientes del pago del impuesto sobre renta se destinen a amortización del capital y intereses deuda interna
