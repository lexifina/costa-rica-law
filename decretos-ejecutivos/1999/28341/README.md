# Decreto Ejecutivo 28341

Convoca con carácter transitorio, a la Reserva de las Fuerzas de Policía, como cuerpo auxiliar extraordinario, con carácter ad honorem, para atender en todo el país los eventos en que se festejan el fin y principio de año
