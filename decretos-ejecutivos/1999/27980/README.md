# Decreto Ejecutivo 27980

Fija nivel máximo de aflotoxinas en el maíz (Zea mays); el arroz (Oryza sativa); el frijol (Phaseolus vulgaris); el trigo (Triticum aestivum) y otros cereales, oleaginosas y leguminosas
