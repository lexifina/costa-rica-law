# Decreto Ejecutivo 27983

Autoriza y Dotar de Investidura como Inspectores de Salud los Funcionarios del Servicio Fitosanitario del Estado, de la Dirección de Salud Animal del MAG, del Consejo de Producción (CNP) y del Programa Integral de Mercadea Agropecuario (PIMA).
