Artículo 3º.-Las solicitudes a que hace referencia el artículo 1º de este Reglamento se clasifican en cuatro grupos tomando en consideración el método de extracción empleado, el destino del material y el tiempo por el cual se solicita la concesión. Dichas solicitudes se clasifican en:
1) Solicitudes de extracción manual de un determinado volumen para destinarlo a uso personal del solicitante y extrayéndose por un determinado tiempo.
2) Solicitudes de extracción mecanizada de un determinado volumen para destinarlo a uso personal del solicitante y extrayéndose por un determinado tiempo.
3) Solicitudes de extracción manual de un determinado volumen para destinarlo a la venta de terceros por un determinado tiempo.
4) Solicitudes de extracción mecanizada de un determinado volumen para destinarlo a la venta de terceros por un determinado tiempo.
