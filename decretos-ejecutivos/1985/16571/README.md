# Decreto Ejecutivo 16571

Las áreas incluidas en la Reserva Indígena Cabécar de Talamanca, Bribrí de Talamanca y Cabécar de Telire correspondientes al Parque Nacional La Amistad y a la Reserva Biológica de Hitoy permanecen bajo régimen de Parques Nacionales
