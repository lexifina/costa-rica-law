# Decreto Ejecutivo 16521

Designa a la Dirección de Racionalización del Estado del MIDEPLAN, como ente responsable de dar seguimiento al cumplimiento de adoptar el respectivo número de cédula, como medio único y uniforme de identificación de las personas físicas o jurídicas
