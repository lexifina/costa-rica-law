# Decreto Ejecutivo 16309

Establece que el nombre de Chase es reservado únicamente al territorio situado entre el río Sixaola, el río Watsi y el límite oeste y sur de la Reserva Indígena Bribrí de Talamanca. Reconoce Caserío Indígena Acberye
