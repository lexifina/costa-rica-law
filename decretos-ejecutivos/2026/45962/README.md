# Decreto Ejecutivo 45962

Reforma Declara como Secreto de Estado y reserva por razones de interés público, seguridad y defensa nacionales, los informes, documentos, archivos o información vinculados con el Consejo Nacional de Seguridad Pública, la Dirección de Inteligencia y Seguridad Nacional, el Grupo de Trabajo del Gobierno de Costa Rica denominado “Fuerza Élite”
