# Decreto Ejecutivo 45830

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre jabones de tocador, mediante un ajuste de cero coma cincuenta y seis por ciento (0,56%)
