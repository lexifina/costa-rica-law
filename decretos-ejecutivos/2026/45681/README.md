# Decreto Ejecutivo 45681

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre jabones de tocador, mediante un ajuste de menos uno coma diez por ciento (-1,10 %)
