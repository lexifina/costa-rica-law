# Decreto Ejecutivo 19046

Autoriza en período entre publicación del presente decreto y 31/07/1989, en zona delimitada por costa y línea recta imaginaria excluyendo área de uso público para bañistas pesca artesanal a personas físicas que cumplan requisitos artículo 16 del DE-16804
