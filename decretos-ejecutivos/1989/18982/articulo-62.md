CAPITULO DECIMOSEGUNDO
Disposiciones varias
Artículo 62.-La Dirección deberá elaborar un sistema adecuado de
asesoramiento para la Confederación, de modo que esta tenga la asesoría
necesaria para la formulación de programas necesarios para el
funcionamiento de la misma. Para este efecto, la Dirección podrá
solicitar a las dependencias del Poder Ejecutivo, los funcionarios
capacitados que sean convenientes para llevar adelante el movimiento
comunal. Salvo casos especiales esta solicitud deberá resolverse
favorablemente mediante convenios especiales donde se soliciten los
servicios de los técnicos que trabajen en las instituciones autónomas y
semiautónomas.
