# Decreto Ejecutivo 36335

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste 1.05%

- Número: 36335
- Fecha: 2010-12-03
- Ente emisor: Poder Ejecutivo
