# Decreto Ejecutivo 36021

Convocatoria y organización de proceso consulta ciudadana para elaboración de política integral y sostenible de seguridad ciudadana y crea Comité Consultivo del proceso de elaboración y adopción de la Política Integral y Sostenible de Seguridad Ciudadana
