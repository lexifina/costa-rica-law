# Decreto Ejecutivo 36166

Declara e Incorporar al Patrimonio Histórico-Arquitectónico de Costa Rica, el inmueble conocido como “Antiguo Templo Católico de San José de Cedral, La Unión de Montes de Oro Puntarenas”
