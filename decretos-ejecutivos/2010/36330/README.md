# Decreto Ejecutivo 36330

Deroga decreto ejecutivo N° 35428 que "Denuncia Convenio Constitutivo del Sistema Económico Latinoamericano (SELA)" y Reincorpora a Costa Rica en el Convenio Constitutivo del Sistema Económico Latinoamericano (SELA) aprobado mediante ley N° 5977
