# Decreto Ejecutivo 36160

Declaratoria de Interés Público y Nacional las acciones tendientes al diseño, financiamiento, construcción, operación y mantenimiento de sistemas de tratamiento de aguas residuales domésticas, provenientes de tanques sépticos y otras obras
