# Decreto Ejecutivo 35716

Emergencia sanitaria de la situación actual del edificio que alberga las oficinas del puesto fronterizo de Peñas Blancas y de interés público nacional las acciones que realicen las autoridades públicas para solucionar dicho problema sanitario
