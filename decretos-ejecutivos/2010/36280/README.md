# Decreto Ejecutivo 36280

Aprueba acuerdo Complementario al Acuerdo de Cooperación Técnica entre Gobierno de la República Federativa de Brasil y el Gobierno de Costa Rica para la implementación del Proyecto "Vigilancia de la salud y sistemas de información para la vigilancia"
