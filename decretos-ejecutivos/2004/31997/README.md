# Decreto Ejecutivo 31997

Prohibe el registro, importación y uso de plaguicidas obsoletos que no se encuentran registrados en el país.

- Tipo: Decreto Ejecutivo
- Número: 31997
- Fecha: 2004-06-28
- Ente emisor: Poder Ejecutivo
