# Decreto Ejecutivo 32005

Autoriza un aumento general al salario base de todos los servidores públicos consistente en un 4.5% (cuatro punto cinco por ciento) a partir del primero de julio del año 2004

- Tipo: Decreto Ejecutivo
- Número: 32005
- Fecha: 2004-08-04
- Ente emisor: Poder Ejecutivo
