# Decreto Ejecutivo 31880

Modifica límite de gasto presupuestario para la Cuenta Especial de la Dirección de Salud y Producción Pecuaria del Ministerio de Agricultura y Ganadería para el año 2004, establecido en las Directrices de política presupuestaria del 2004.
