# Decreto Ejecutivo 32284

Personas que en virtud del Primer Procedimiento Especial Abreviado de Taxis o concursos similares promovidos por el Consejo de Transporte Público hayan resultado adjudicados de concesión administrativa de taxi, podrán solicitar el cambio del vehículo
