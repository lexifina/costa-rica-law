# Decreto Ejecutivo 31784

Declara de interés público y nacional, las actividades que llevará a cabo la Red Médica, con motivo de la celebración del I Congreso Internacional sobre Hospitales Domiciliarios, Cirugía Ambulatoria, Dolor y Cuidados Paliativos
