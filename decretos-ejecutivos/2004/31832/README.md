# Decreto Ejecutivo 31832

Indica el establecimiento una Comisión Interdisciplinaria Marino Costera de la Zona Económica Exclusiva para determinar viabilidad de dedicar hasta un 25% de dicha zona a la conservación, restauración, manejo y aprovechamiento sostenible de especies
