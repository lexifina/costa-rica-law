# Decreto Ejecutivo 31648

Amplía alcances del Programa Bandera Azul Ecológica, como incentivo para organizar a educadores, educandos y personal administrativo de centros educativos, con el fin de promover la adopción de prácticas sostenibles y amigables con el ambiente
