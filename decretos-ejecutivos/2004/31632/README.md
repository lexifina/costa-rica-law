# Decreto Ejecutivo 31632

Otorga plazo a la Administración Forestal del Estado para realizar auditoría a permisos de inventario forestal otorgados del 1° de enero al 29 de octubre de 2003 y mantiene por 90 días restricción de corta de árboles
