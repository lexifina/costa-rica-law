# Decreto Ejecutivo 31785

Declara de interés público y nacional, las actividades que llevará a cabo la Asociación Costarricense de Patología, con motivo de la celebración del VI Congreso Nacional de Patología y del XXVII Congreso Centroamericano de Patología
