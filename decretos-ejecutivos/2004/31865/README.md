# Decreto Ejecutivo 31865

Prorroga la vigencia del Decreto Ejecutivo de Apertura arancelaria y modificación de los Derechos Arancelarios a la Importación de Pinturas y Barnices a base de polímeros sintéticos o naturales o modifcados dispersos o disueltos en un medio acuoso.
