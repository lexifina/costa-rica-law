# Decreto Ejecutivo 2217

Deroga decreto que establece que la venta de soluciones anestésicas o sus sales básicas deberá ser mediante prescripción facultativa de Médicos Cirujanos Dentistas y Veterinarios, Miembros de los Colegios respectivos
