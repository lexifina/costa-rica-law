# Decreto Ejecutivo 32339

Reforma decreto que determina que previo a la autorización para la importación de arroz, deben ser sometidas a una evaluación de riesgo de conformidad con la Norma Técnica RTCR 379-2000

- Número: 32339
- Fecha: 2005-04-15
