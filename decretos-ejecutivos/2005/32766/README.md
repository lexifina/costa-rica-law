# Decreto Ejecutivo 32766

Autoriza la importación de veintidós mil seiscientas treinta y ocho toneladas métricas (22.638 TM), de maíz blanco, con una tarifa de cero por ciento (0%) de Derechos Arancelarios a la Importación

- Tipo: Decreto Ejecutivo
- Número: 32766
- Fecha: 2005-10-12
- Ente emisor: Poder Ejecutivo
