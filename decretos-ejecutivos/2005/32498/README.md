# Decreto Ejecutivo 32498

Declara de interés público y nacional, las actividades que llevará a cabo la Sociedad Costarricense de Mesoterapia Uno Sociedad Anónima, con motivo de la celebración del curso de Primer Nivel Internacional de Mesoterapia General y Medicina Estética
