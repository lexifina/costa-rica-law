# Decreto Ejecutivo 32539

La Autoridad presupuestaria considerará la solicitud presentada por el Consejo de Transporte Público, con el fin de implementar la estructura orgánica y el Manual Institucional de Clases aprobado por la Dirección General del Servicio Civil
