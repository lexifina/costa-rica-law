# Decreto Ejecutivo 32822

Se autoriza al Instituto Mixto de Ayuda Social para destinar recursos propios para el pago de cuotas atrasadas por concepto de vivienda de interés social, para familias que figuren como deudores en los respectivos fideicomisos
