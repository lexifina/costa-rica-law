# Decreto Ejecutivo 32779

Se autoriza la importación como desabasto de noventa mil setecientas trece toneladas métricas de arroz en granza (90.713 T. M ) con una tarifa de cero por ciento ( 0% ) de derechos arancelarios a la importación
