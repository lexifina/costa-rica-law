# Decreto Ejecutivo 32751

La Autoridad Presupuestaria considerará la solicitud presentada por la Junta Administrativa del Registro Nacional, con el fin de establecer mecanismos de control interno que garanticen la seguridad jurídica de los bienes inscritos en el Registro Nacional
