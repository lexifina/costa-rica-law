# Decreto Ejecutivo 32426

Prorroga por doce meses mas al ICAFE, autorización para habilitar temporalmente como bodegas del Almacén General de depósito, las instalaciones (bodegas y silos) de los beneficios de café, según requisitos establecidos en DE-29945
