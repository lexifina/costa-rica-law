# Decreto Ejecutivo 40105

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste del -0.59%

- Número: 40105
- Fecha: 2016-12-08
