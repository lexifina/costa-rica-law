# Decreto Ejecutivo 39838

Faculta al SINAC para autorizar la intervención controlada a ecosistemas de humedal en virtud de proyectos de reparación y mantenimiento, construcción o ampliación de infraestructura pública estatal previamente declarados de conveniencia nacional
