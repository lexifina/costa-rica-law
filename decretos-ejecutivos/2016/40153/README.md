# Decreto Ejecutivo 40153

Promulga teniendo como vigente el Acuerdo bajo la modalidad de Canje de Notas constituido entre Costa Rica y la República Federal de Alemania sobre el proyecto "Café de Costa Rica Bajo en Emisiones proyecto de apoyo a la NAMA"
