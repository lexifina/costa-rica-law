# Decreto Ejecutivo 38398

Declara zona catastrada el distrito primero Tres Ríos, segundo San Diego, tercero San Juan, cuarto San Rafael, quinto Concepción, sexto Dulce Nombre, sétimo San Ramón, octavo Río Azul del Cantón 03 de la Unión de la Provincia 03 Cartago
