# Decreto Ejecutivo 38383

Se insta al Consejo de Transporte Público proceda a implementar el sistema integral de rutas intersectoriales la puesta en marcha de la ruta intersectorial descrita como “Guadalupe-Moravia-La Valencia” y viceversa
