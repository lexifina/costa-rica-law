# Decreto Ejecutivo 38384

Se insta al Consejo de Transporte Público proceda a implementar el sistema integral de rutas intersectoriales la puesta en marcha de la ruta intersectorial descrita como “Santa Ana-San Antonio de Belén-La Valencia” y viceversa
