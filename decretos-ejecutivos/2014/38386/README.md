# Decreto Ejecutivo 38386

Se insta al Consejo de Transporte Público para que proceda a implementar el sistema integral de rutas intersectoriales la puesta en marcha de la ruta intersectorial descrita como “Hatillo-Paso Ancho-Zapote-San Pedro-Guadalupe” y viceversa
