# Decreto Ejecutivo 38818

Publica Resolución N° 347-2014 (COMIECO-LXVIII) del 27 de junio de 2014: Otorga "un plazo hasta el 31 de marzo de 2015 para que las empresas presenten ante la autoridad sanitaria un plan de cumplimiento que permita ajustar el etiquetado nutricional"
