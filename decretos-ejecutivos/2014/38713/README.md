# Decreto Ejecutivo 38713

Prohibición del registro, importación, exportación, fabricación, formulación, almacenamiento, distribución, transporte, reempaque, reenvase, manipulación, venta, mezcla, uso de ingredientes grado técnico y plaguicidas que contengan carbofurán
