# Decreto Ejecutivo 38671

Publica Acuerdo N° 02-2014 (COMIECO-LXVIII) de 27/06/2014, autoriza a SIECA para que contrate servicios de hospedaje de procesamiento y almacenamiento de datos en un esquema de nube para alojar los sistemas y datos que se utilizan para comercio
