# Decreto Ejecutivo 39538

Declara la Región Brunca de la República de Costa Rica como zona de baja prevalencia de Brucelosis y Tuberculosis Bovina y reforma Reglamento General para el Otorgamiento del Certificado Veterinario de Operación
