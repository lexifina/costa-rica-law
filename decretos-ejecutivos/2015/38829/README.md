# Decreto Ejecutivo 38829

Declara de interés público el proceso de evaluación mutua de Costa Rica, sobre el lavado de dinero y el financiamiento al terrorismo en cumplimiento efectivo de las recomendaciones del grupo de acción financiera internacional
