# Decreto Ejecutivo 39298

Declaratoria de Emergencia Sanitaria en Territorio Indígena Cabecar de Tayni y comunidades cercanas por deficiencias en el suministro de agua apto para consumo humano y falta de acceso para brindar servicios de salud y la construcción de sus acueducto
