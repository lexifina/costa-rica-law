# Decreto Ejecutivo 34764

Actualiza montos de impuestos específicos, para las mercancías de producción nacional e importadas, establecidos en el artículo 9º de la Ley Nº 8114 ( Bebidas Envasadas sin Contenido Alcohólico, Excepto la Leche y sobre Jabones de Tocador)
