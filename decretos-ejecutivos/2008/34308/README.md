# Decreto Ejecutivo 34308

Publica Resolución N° 217-2007 (COMIECO- XLVII) Aprueba modificaciones a Derechos Arancelarios a la Importación de los incisos arancelarios los cuales forman parte integrante del Anexo “A” del Convenio sobre Régimen Arancelario y Aduanero Centroamericano
