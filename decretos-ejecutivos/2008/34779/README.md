# Decreto Ejecutivo 34779

Declara de interés público y nacional, las actividades que llevará a cabo la Asociación Costarricense de Cardiología, con motivo de la celebración del Simposio “De Insuficiencia Cardiaca a Prevención y Rehabilitación Cardiovascular”
