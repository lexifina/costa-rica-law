# Decreto Ejecutivo 34310

Publica Resolución Nº 220-2007 (COMIECO-EX) Aprueba modificaciones a Derechos Arancelarios a la Importación de los incisos arancelarios los cuales forman parte integrante del Anexo “A” del Convenio sobre Régimen Arancelario y Aduanero Centroamericano
