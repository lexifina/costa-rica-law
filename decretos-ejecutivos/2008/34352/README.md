# Decreto Ejecutivo 34352

Se autoriza la importación de cien mil kilogramos de arroz (100.000 Kg.), con una tarifa de cero por ciento (0%) de Derechos Arancelarios a la Importación (Autorización para importar arroz utilizado para el proceso de insuflado)

- Tipo: Decreto Ejecutivo
- Número: 34352
- Fecha: 2008-01-07
- Ente emisor: Poder Ejecutivo
