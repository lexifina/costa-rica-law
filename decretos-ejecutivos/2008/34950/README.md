# Decreto Ejecutivo 34950

Deroga decreto que prohibe el registro, formulación, fabricación, importación, exportación, tránsito, depósito, almacenamiento, venta, uso agrícola, del formicida Cianamida de Calcio y de productos de una fórmula química, N° 27771 del 19/05/1998
