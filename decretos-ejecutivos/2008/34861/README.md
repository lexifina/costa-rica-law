# Decreto Ejecutivo 34861

La prevención y control de moscas blancas y áfidos en la Península de Nicoya: Nicoya, Carmona, Lepanto, Jicaral, Chomes y Abangaritos, que afectan la producción de melón y sandía para la exportación y consumo nacional
