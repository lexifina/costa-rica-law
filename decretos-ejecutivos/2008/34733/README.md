# Decreto Ejecutivo 34733

Convoca conforme lo solicitado por la Ministra de Seguridad Pública, y con carácter de transitorio a la Reserva de las Fuerzas de Policía para atender y coordinar con autoridades de policía, las labores de vigilancia y protección de la seguridad pública
