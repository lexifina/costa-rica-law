# Decreto Ejecutivo 25727

Autoriza al Instituto de Desarrollo Rural, para que proceda a solicitar al Registro Público la afectación de fincas, con el objeto de que los ocupantes y poseedores en dichas áreas puedan obtener su título de propiedad
