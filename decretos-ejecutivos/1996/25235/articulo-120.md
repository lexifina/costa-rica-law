Artículo 120.- Los locales para el almacenamiento de explosivos no
deben pasar las siguientes temperaturas máximas:
- 27º C para nitrocelulosa, nitromido y pólvora química de base doble,
- 30º C para ácido picrico y pólvora química de base simple,
- 35º C para pólvora mecánica,
- 40º C para trotil, nitrato de amonio mezclado con diesel, picrato de
amonio u otros explosivos no especificados.
