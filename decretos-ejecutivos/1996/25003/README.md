# Decreto Ejecutivo 25003

Las empresas beneficiarias del régimen de zona franca, están obligadas a presentar ante la Corporación de la Zona Franca de Exportación un informe anual de sus actividades

- Número: 25003
- Fecha: 1996-02-21
