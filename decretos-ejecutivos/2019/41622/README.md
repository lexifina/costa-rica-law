# Decreto Ejecutivo 41622

Autoriza al Consejo de Salud Ocupacional para que en el ejercicio presupuestario correspondiente al año 2019 empleen recursos correspondientes a superávit libre para financiar gastos operativos según Ejecutivo N° 40540-H
