# Decreto Ejecutivo 42105

Actualización de los impuestos específicos sobre las bebidas envasadas sin contenido alcohólico, excepto la leche y sobre los jabones de tocador, mediante un ajuste de cero coma cuatro por ciento (0.04%)

- Tipo: Decreto Ejecutivo
- Número: 42105
- Fecha: 2019-12-09
- Ente emisor: Poder Ejecutivo
