# Decreto Ejecutivo 41570

Autoriza al Museo Histórico Cultural Juan Santamaría y al Consejo Nacional de Política Pública de la Persona Joven según el ejercicio económico 2019 para emplear recursos de correspondientes a superávit libre para financiar gastos operativos
