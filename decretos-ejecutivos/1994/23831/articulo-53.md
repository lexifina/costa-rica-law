Artículo 53.- En el caso de automotores equipados con motor de
gasolina, adicionalmente se debe verificar mediante inspección
visual el estado del sistema de emisiones original para determinar
si está integrado al sistema de escape y comprobar que no sufra
deterioro considerable. También se debe revisar que el vehículo
cuente con la etiqueta de control de emisiones que el fabricante
normalmente coloca cuando un vehículo fue construido para cumplir
estándares de emisiones.
