Artículo 24.—El uso de las áreas destinadas para estacionamiento, queda restringido a que el usuario se encuentre dentro de las instalaciones.
Bajo ninguna circunstancia se permitirá la utilización de esas áreas si el usuario no está o no se mantiene dentro del CUNA. De presentarse dicha situación, se podrá suspender de inmediato el derecho de acceso.
