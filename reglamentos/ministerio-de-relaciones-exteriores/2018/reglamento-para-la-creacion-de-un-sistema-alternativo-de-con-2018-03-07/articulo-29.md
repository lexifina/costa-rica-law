CAPÍTULO IV
Del proceso de control de ejecución del servicio
Artículo 29. Control de Responsables.
La Proveeduría Institucional mantendrá la base de datos de registros de firmas de funcionarios autorizados para gestionar la compra de boletos, compartida para los usuarios del Servicio. Cualquier cambio que se gestione de responsables, así como cualquier resolución de autorización para trámites de boletos, deberá ser comunicado a la Proveeduría Institucional.
