CAPÍTULO I
Disposiciones Generales
Artículo 1º—Definición de Base de Datos de Voces Judicial. Se entenderá como base de datos de voces judicial, como el conjunto estructurado de archivos sonoros de voces cuyos locutores fueron captados personalmente durante el proceso de reseña policial, que son almacenados y tabulados con sus respectivos datos personales de manera independiente con finalidad exclusiva de identificación personal, la cual con el fin de identificación institucional en adelante se denominará “Sistema Integrado de Voces”, cuyas siglas serán “SIV”.
