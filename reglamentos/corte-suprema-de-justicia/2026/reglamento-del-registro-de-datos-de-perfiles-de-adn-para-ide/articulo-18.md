CAPÍTULO III
ORGANIZACIÓN Y ADMINISTRACIÓN DE LA BASE DE DATOS DE ADN
Artículo 18°-Organización de la Base de Datos de ADN.
La Base de Datos de ADN se encuentra integrada por:
1.- El Archivo de Información Personal del donante de la muestra biológica, el cual se encuentra integrado por el nombre y apellido de la persona que ingresa a la base de datos y número de identificación personal.
2.- El Archivo de los Perfiles Genéticos, donde se archivan los perfiles genéticos a través de un código alfanumérico de identificación único.
Ambos archivos son independientes entre sí.
