Artículo 2º.- De las definiciones.
Para efectos del presente reglamento se entenderá por:
Base de Datos de ADN: se entenderá como Base de Datos de Ácido Desoxirribonucleico (ADN), el conjunto estructurado de Archivos de Perfiles Genéticos y de Datos Personales, almacenados de manera independiente, de tratamiento o procesamiento automatizado, con finalidad exclusiva de identificación humana.
Epitelio bucal: muestra biológica consistente en células desprendidas de la mucosa interna de las mejillas, obtenida mediante el uso de un hisopo o aplicador para fines de identificación humana.
Persona investigada: persona de interés para la Policía Judicial por encontrarse relacionada en un hecho punible sometido a una investigación en curso.
Investigación Penal: encadenamiento de diligencias técnicas, científicas y jurídicas dirigidas al descubrimiento de los responsables de un delito.
Muestra Biológica: cualquier vestigio biológico de carácter humano destinado al análisis de ADN, que puede tener o no un origen conocido.
Muestras Dubitadas: son todas aquellas muestras biológicas de origen desconocido.
Muestras Indubitadas: son todas aquellas muestras biológicas de origen conocido, obtenidas de las personas investigadas, víctimas y de familiares de personas desaparecidas.
Perfil Genético: Se entiende como perfil genético o huella genética, para estos efectos, el registro alfanumérico personal, elaborado exclusivamente sobre la base de información genética no codificante, con fines exclusivamente de carácter identificatoria
