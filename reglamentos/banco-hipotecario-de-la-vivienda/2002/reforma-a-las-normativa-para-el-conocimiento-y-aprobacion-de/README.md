# Reglamento (2002-02-20)

Reforma a las Normativa para el conocimiento y aprobación de las solicitudes de subsidio para la erradicación de tugurios y asentamientos en precario, y para la atención de problemas vivienda ocasionados por situaciones de emergencia.
