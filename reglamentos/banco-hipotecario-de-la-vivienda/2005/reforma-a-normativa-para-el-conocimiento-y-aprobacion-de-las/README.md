# Reglamento (2005-02-15)

Reforma a Normativa para el conocimiento y aprobación de las solicitudes de subsidio para la erradicación de tugurios y asentamientos en precario, y para la atención de problemas de vivienda ocasionados por situaciones de emergencia o extrema necesidad.
