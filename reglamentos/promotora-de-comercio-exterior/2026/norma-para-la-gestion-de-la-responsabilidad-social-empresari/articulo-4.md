Artículo 4.- Gestión de partes interesadas
La Gerencia General o la persona funcionaria designada al efecto gestiona las partes interesadas:
Realizando análisis periódicos de las partes interesadas de PROCOMER con el Staff Gerencial. Este análisis incluye:
Revisión y actualización de partes interesadas.
Identificación de requisitos de valor para cada una de las partes interesadas.
Identificación de nivel de poder para cada una de las partes interesadas.
Asegurando el apoyo y la buena relación con las partes interesadas
