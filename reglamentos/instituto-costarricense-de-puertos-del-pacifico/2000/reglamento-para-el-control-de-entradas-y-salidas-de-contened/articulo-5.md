Artículo 5°—Del ingreso de contenedores para embarque indirecto. El ingreso de contenedores llenos o vacíos para el embarque indirecto, se realiza mediante el procedimiento de un formulario denominado "entrada" (In Gate). Este formulario es llenado por el cheque de intercambio, el cual contiene los siguientes datos:
Número de contenedor
Tamaño
Si se encuentra lleno o vacío
Nombre del buque
Peso, Agencia, entre otros aspectos
Siempre cumpliendo con los requisitos aduaneros como los son las pólizas.
