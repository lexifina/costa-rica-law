Funcionamiento
Artículo 7°—Los fondos fijos para la Caja Chica, la Boletería, y e monto máximo de compras por Caja Chica para cada programa será el siguiente:
a. La Dirección Ejecutiva del Teatro Popular Mélico Salazar administrará un monto de Caja Chica de 0 100.000,00 siendo el monto máximo de compras por medio de Caja Chica de 0 10.000,00 y el monto de la Boletería se fija en 0 50.000,00.
b. La Compañía Nacional de Danza administrará un monto fijo de Caja Chica de 0 100.000,00, el monto máximo para compras de Caja Chica será de 0 10.000,00 siendo el monto fijo de Boletería de 050.000,00.
c. La Compañía Nacional de Teatro administrará un monto fijo de Caja Chica de 0 100.000,00, siendo el monto máximo para compras de Caja Chica de 0 10.000,00 y el monto de Boletería será 0 50.000,00.
d. Para el Taller Nacional de Teatro, administrará un monto fijo de Caja Chica de 0 25.000,00, y el monto máximo de compras por medio de Caja Chica de 0 2.500,00.
e. Para el Taller Nacional de Danza, administrará un monto fijo de Caja Chica de 0 50.000,00 y el monto máximo de compras por medio de Caja Chica será de 0 5.000,00.
f. Asimismo, para el Festival Nacional de las Artes administrará un monto fijo de Caja Chica de 0 50.000,00, y el monto máximo para compras por medio de Caja Chica de 0 5.000,00 y el monto de Boletería será de 0 50.000,00.
