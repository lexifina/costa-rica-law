Artículo 18. Se establece como el sistema oficial para realizar las compras con fondos de caja chica el módulo de ERP llamado Compras no ordinarias. El uso de tarjeta de compras institucional constituye una excepción al medio de pago usual de la Institución de transferencia electrónica. El pago por tarjeta de compra institucional se regula mediante la directriz de Órganos competentes para autorizar compras con fondos de Caja Chica que emita la Gerencia General.
