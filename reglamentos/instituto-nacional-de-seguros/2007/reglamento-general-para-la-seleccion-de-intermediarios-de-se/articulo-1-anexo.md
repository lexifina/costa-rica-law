4. ASPECTOS GENERALES DE LA EVALUACIÓN.
4.1 Base de calificación: La calificación se realiza con base cien, lo cual implica la máxima cantidad que puede obtener un oferente es de cien puntos.
4.2 Criterio para redondeo: Para los cálculos de puntaje que impliquen el manejo de decimales se utilizará el truncar en dos decimales.
4.3 Elegibilidad. Se considerarán elegibles las ofertas que obtengan una calificación de 70 o más.
4.4 En caso de ofertas con menor puntaje al requerido el Instituto se reserva el derecho de adjudicar, siempre y cuando existan razones justificadas y el servicio no se vea deteriorado por esta condición.
