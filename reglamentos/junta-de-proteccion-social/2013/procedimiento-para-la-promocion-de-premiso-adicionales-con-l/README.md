# Reglamento (2013-02-21)

Procedimiento para la promoción de premiso adicionales con los "sorteos ordinarios y extraordinarios de Lotería Popular", así como para los sorteos de "Números bajos 00-49" y el sorteo "Viernes Negro" de Lotería Popular para el año 2013
