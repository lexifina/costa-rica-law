Artículo 73.—Requisitos: A- Cumplir con los requisitos generales de este reglamento. B- Cancelar el monto establecido para este estudio. C- Indicar dirección exacta, incluyendo provincia, cantón, distrito y otras señas o puntos de referencia donde se instalará el servicio temporal. D- Suministrar la lista de la carga a conectar (cantidad de bombillos, equipos, artefactos eléctricos y el voltaje de cada uno).
