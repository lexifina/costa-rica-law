Artículo 26.—Servicio provisional: Consiste en la instalación de un medidor para inicio de construcción, es de carácter temporal y el plazo máximo que se concede es de seis meses; si después de este periodo no se concluye la obra el cliente deberá solicitar la renovación del plazo concedido, de lo contrario JASEC tendrá la potestad de notificarle y eventualmente suspender el servicio. Para atender este se requerirá la apertura de una OT.
