Artículo 45.—Procedimiento: A- Solicitar el servicio en la Plataforma de Servicios de JASEC. B- Cumplir con los requisitos establecidos. C- Para la respectiva liquidación de un servicio temporal, el cliente que solicitó el servicio es quien debe realizar la liquidación ante la Plataforma de Servicios y se procede a: 1- Verificar que la información (lectura de retiro, estado del medidor) del servicio temporal, ya se haya ingresado al sistema, para poder realizar la liquidación. 2- Se procede a realizar el cálculo del consumo para determinar si el depósito otorgado por el cliente cubre el importe total de consumo. En caso de existir un monto a favor del cliente se procede con la gestión de la devolución, de lo contrario el cliente deberá cancelar la diferencia mediante un recibo especial.
