Artículo 61.—Requisitos: A- Cumplir con los requisitos generales de este reglamento. B- Cancelar el monto establecido para este trámite, el cual contempla únicamente la elaboración del estudio. C- Presentar copia del plano catastro de la propiedad donde se llevará a cabo el estudio. D- Indicar dirección exacta, incluyendo provincia, cantón, distrito y otras señas o puntos de referencia donde se debe realizar el estudio.
