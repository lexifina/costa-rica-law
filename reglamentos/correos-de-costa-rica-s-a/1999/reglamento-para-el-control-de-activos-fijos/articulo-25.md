Artículo 25.—Traslado de activos a otras oficinas. Cuando se realice el traslado de un activo a otra oficina, se deberá confeccionar la boleta de "traslado de activos", confeccionando una boleta por cada activo, en original y tres copias, el original será para el Departamento de Contabilidad, una copia para el Departamento de Compras y Contrataciones, una copia para la oficina que recibe el bien y una copia para la oficina que realiza el traslado, con el fin de mantener actualizada la base de datos del Sistema de Activos.
