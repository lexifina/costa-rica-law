CAPÍTULO III: RECLUTAMIENTO Y SELECCIÓN DE PERSONAL
Artículo 4: Registro en Base de Datos
Todas las personas externas interesadas en ofertar sus servicios para efectos de un concurso, deberán de forma voluntaria y consensuada registrar su currículo en el sitio web que se utilice para tales efectos. El postulante deberá gestionar las acciones pertinentes requeridas para formar parte de las base de datos de oferentes.
