CAPÍTULO II
Términos y definiciones
900ENLÍNEA: Servicio de RACSA mediante el cual una persona puede tener acceso a la red de Internet haciendo una llamada al 900-365-4632.
Bloqueo de una dirección IP: Desactivación del acceso de un cliente a la red de Internet.
Cable Módem: Es un dispositivo que permite conectar una computadora a una línea local de cable para recibir datos.
Cliente conmutado: Aquel que conecta a la red de Internet a través de una llamada telefónica.
Cliente dedicado: Aquel que conecta a la red de Internet a través de un enlace permanente.
Co-Location: Alquiler de espacio físico para el alojamiento de equipos y servidores que permite el acceso a redes de comunicaciones privadas o públicas desde este espacio físico.
Correo Electrónico: Toda correspondencia, mensaje, archivo, dato u otra información electrónica que se transmite a una o más personas por medio de una red de interconexión entre computadoras.
Cuenta Permanente: Paquete que se obtiene mediante la firma previa de un contrato.
Dirección IP: Dirección única de un usuario conectado a la red de Internet.
Encabezados desplegados: Es el encabezado de correo electrónico en forma ampliada en donde se muestran los servidores, origen y ruta completa del mensaje.
Internet directo: Servicio de RACSA que provee conexiones satelitales privadas.
Internet XPRESS: Servicio de RACSA mediante el cual una persona puede tener acceso a la red de Internet adquiriendo una tarjeta pre-pago, la cual trae consigo un nombre de usuario y una contraseña para acceder el servicio.
Nombre de usuario: Conocido también como username ó login. Es la identificación que se le asigna al cliente cuando este adquiere un contrato.
RACSA: Radiográfica Costarricense, S. A.
Usuario: La persona física o jurídica que hace uso de los servicios de la red de Internet.
