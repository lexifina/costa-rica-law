Artículo 25. Para cada operación estadística se deberán respaldar las siguientes bases de datos: i.) la base de datos original con la captura de los datos sin ningún tipo de tratamiento; ii) la base de datos una vez aplicados procedimientos de codificación, depuración de inconsistencias, imputaciones y ajustes a las variables cuando procede; iii) la base de datos con las variables creadas elaborada para los usuarios para ser entregada bajo licencia y de uso restringido iv) la base de datos de uso público.
