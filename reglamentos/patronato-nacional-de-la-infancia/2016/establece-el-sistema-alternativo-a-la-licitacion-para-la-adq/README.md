# Reglamento (2016-12-06)

Establece el sistema Alternativo a la licitación para la adquisición de ropa y accesorios, calzado regalo navideño, uniformes escolares, útiles, etc, para uso de los niños(as) y adolescentes ubicados en los albergues y aldeas del Patronato Nacional (PANI)
