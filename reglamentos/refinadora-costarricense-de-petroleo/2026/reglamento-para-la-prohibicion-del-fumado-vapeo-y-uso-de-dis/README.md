# Reglamento (2026-08-18)

Reglamento para la prohibición del fumado, vapeo y uso de dispositivos de administración de nicotina (SEAN), sistemas similares sin nicotina (SSSN) y dispositivos electrónicos que utilizan tabaco calentado y tecnologías similares en las instalaciones de RECOPE
