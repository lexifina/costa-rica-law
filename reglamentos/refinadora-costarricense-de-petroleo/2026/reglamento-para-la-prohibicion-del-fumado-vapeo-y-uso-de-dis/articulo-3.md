Artículo 3. Definiciones
Para efectos de este Reglamento se entenderá por:
a) Fumar: inhalar, exhalar, quemar o mantener encendido cualquier producto de tabaco o sustancia similar.
b) Vapear: utilizar dispositivos electrónicos que generen vapor o aerosol para inhalación.
c) Cigarrillo electrónico: dispositivo electrónico utilizado para vaporizar líquidos con o sin nicotina.
d) Sistema Electrónico de Administración de Nicotina (SEAN): dispositivo definido como tal por la legislación nacional vigente.
e) Sistema Similar Sin Nicotina (SSSN): dispositivo definido como tal por la legislación nacional vigente.
f) Áreas operativas: instalaciones industriales destinadas al almacenamiento, transporte, bombeo, carga, descarga, medición o manejo de hidrocarburos y productos asociados.
g) Área clasificada: zona identificada conforme a normativa técnica de atmósferas potencialmente explosivas o inflamables según NFPA 70 para cualquiera de las clases (I, II y III) y abarcando todas las Divisiones (Según NEC) y/o todas las Zonas (Según IEC).
