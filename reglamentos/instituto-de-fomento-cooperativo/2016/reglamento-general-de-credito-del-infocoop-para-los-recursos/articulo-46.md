Artículo 46—Excepción al proceso de cobro administrativo. Cuando existan circunstancias que podrían constituir un grave riesgo para los intereses del INFOCOOP, el Área de financiamiento le solicitara la autorización expresa a la Dirección Ejecutiva para iniciar con el proceso de cobro judicial o proceso de ejecución si se tratara de un fideicomiso de garantía, aunque se encuentre dentro del plazo de cobro administrativo.
