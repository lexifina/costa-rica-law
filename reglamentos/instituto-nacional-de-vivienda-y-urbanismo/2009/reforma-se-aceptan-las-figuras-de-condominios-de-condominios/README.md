# Reglamento (2009-08-19)

Reforma Se aceptan las figuras de condominios de condominios, condominios mixtos, proyectos de condominios en una finca filial de un condominio madre, reforma reglamento para el Control Nacional de Fraccionamientos y Urbanizaciones
