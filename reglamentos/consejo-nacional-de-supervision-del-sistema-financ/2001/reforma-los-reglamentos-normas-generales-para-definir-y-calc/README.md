# Reglamento (2001-06-11)

Reforma los reglamentos "Normas Generales para definir y calcular el Patrimonio no redimible de las entidades fiscalizadas por la SUGEF" y "Normas para establecer la suficiencia de Entidades fiscalizadas por la SUGEF" y otros.
