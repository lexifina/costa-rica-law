Artículo 3) Objetivos específicos
1. Definir las responsabilidades y acciones específicas que tiene que asumir cada persona que interactúe con el sistema de Seguridad de Usuarios para otorgar permisos en el Sistema de Gestión de los Despachos Judiciales y del Sistema Escritorio Virtual.
2. Brindar una guía clara para el uso del sistema de Seguridad de Usuarios de Gestión.
3. Controlar en bitácora el otorgamiento de permisos mediante el uso sistema de Seguridad de Usuarios de Gestión.
