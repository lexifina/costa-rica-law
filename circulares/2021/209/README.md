# Circular 209

Se hace de conocimiento de los jueces y juezas que tramitan la materia civil, sobre admisión de la acción de inconstitucionalidad, para declarar inconstitucionalidad del artículo 2.18 del Reglamento de Normas Prácticas para la aplicación del nuevo Código
