# Circular 172

Se deja sin efecto la circular N° 133-2021 y se mantiene la vigencia de la circular N° 198-2013 y sus reiteraciones en las circulares N° 177-2015, 162- 2018 y 146-2019; hasta tanto sean valoradas por las diferentes instancias
