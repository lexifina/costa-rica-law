# Circular 209

Deber de la Dirección de Tecnología de la Información de verificar la correcta instalación de las mejoras desarrolladas para la implementación del nuevo Código Procesal Civil así como de los Despachos Civiles, Cobratorios y Concursal de ponerlas en prácti
