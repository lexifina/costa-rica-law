# Circular 12-2007-04-26

Las entidades no supervisadas por entes como CONASSIF integrado por SUGEF,SUGEVAL o SUPEN específicamente asociaciones cooperativas, solidaristas y otras de naturaleza similar o siendo estas entidades supervisadas requieran preparar, presentar sus estados
