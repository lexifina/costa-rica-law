# Circular 177

Ampliación de la competencia del Tribunal de Apelación Contencioso Administrativo para conocer asuntos de puro derecho, a partir del 02 de febrero de 2026. Al respecto, se aclara que esta Circular informativa no limita ni condiciona la atención de los asuntos de Puro Derecho ya iniciada en el Tribunal de Apelaciones
