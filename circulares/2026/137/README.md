# Circular 137

Competencia territorial definitiva del Juzgado de Ejecución Laboral en los cantones de San José, Escazú, Santa Ana, Mora, Puriscal, Turrubares, Dota, Tarrazú y León Cortés, excluyendo cualquier ampliación territorial
