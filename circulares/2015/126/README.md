# Circular 126

Deber de enviar las sentencias y autos con carácter de sentencia, al buzón del Sistema Costarricense de Información Jurídica (SCIJ) provisto en el Sistema de Gestión y activar el indicador de Datos Sensibles cuando estas resoluciones los contenga
