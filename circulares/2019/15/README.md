# Circular 15

Importancia de mantener actualizado los sistemas informáticos y efectuar un registro diario y actualizado de la información de esos sistemas, entre ellos el Sistema Costarricense de Gestión de Despachos Judiciales (SCGDJ) y el de la Agenda “Cronos”
