# Circular 49

Se deja sin efecto la Circular Nº 151-2002, "Sobre solicitudes de asueto ante la Dirección Ejecutiva"; y en su lugar se rebaja a diez días hábiles el plazo para gestionar la declaratoria de asueto, por celebraciones cantonales
