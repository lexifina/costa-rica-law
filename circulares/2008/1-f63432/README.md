# Circular 1-f63432

Asociaciones Cooperativas no supervisadas por entes reguladores como CONASSIF integrado por SUGEF,SUGEVAL o SUPEN o siendo estas entidades supervisadas, requieran preparar y presentar sus estados financieros a usuarios distintos de esos entes reguladores
