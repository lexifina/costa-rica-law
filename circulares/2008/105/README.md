# Circular 105

A partir del 1° de febrero del 2008, los Juzgados Penales Juveniles del Primer Circuito Judicial de San José, Alajuela, Cartago, Heredia y Puntarenas atenderán disponibilidad en forma exclusiva con colaboración de Juzgados Penales de localidad
