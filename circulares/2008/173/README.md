# Circular 173

A servidores del Segundo Circuito Judicial de San José a partir del 1° de octubre de 2008 entrará en funcionamiento la consulta en línea de asuntos que se tramitan en esa jurisdicción territorial por esa razón es obligatorio el uso del sistema de gestión
