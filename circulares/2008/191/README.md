# Circular 191

Deber del Juez penal en la disponibilidad de atender asuntos de pensiones alimentarias y obligación de los oficiales de Seguridad de colaborar en la ubicación -en horas no hábiles- del juez encargado de atender la materia de pensiones alimentarías
