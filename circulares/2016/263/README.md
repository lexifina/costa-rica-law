# Circular 263

Directrices para los informes de Tribunales Civiles reflejen con mayor precisión tipos de resoluciones que ingresan, con finalidad que sean delimitados los verdaderos pesos absolutos y relativos en la distribución de casos por tipo de apelación presentada
