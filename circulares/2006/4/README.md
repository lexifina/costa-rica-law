# Circular 4

Resolución que ordena suspensión de licencia de conducir, así como lista de éstas, se debe remitir a la Dirección de Educación Vial, Departamento de Licencias y Consejo de Seguridad Vial, Departamento de Infracciones, para que se suspenda formalmente
