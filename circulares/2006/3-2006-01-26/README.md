# Circular 3-2006-01-26

Resuelve que Entidades, Grupos y Conglomerados Financieros sujetos a Supervisión de SUGEF, SUGEVAL y la SUPEN deben cumplir con los requerimientos relativos al contenido, presentación, información complementaria y publicación de los estados financieros
