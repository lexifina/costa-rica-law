# Circular 231

Deberán los Centros Gestores u oficinas que ejecutan presupuesto -realizar las gestiones que correspondan de forma eficiente y eficaz, para lograr una oportuna ejecución de los recursos presupuestarios del presente periodo presupuestario 2025
