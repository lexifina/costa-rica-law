# Circular 53

Lineamientos a seguir para las comunicaciones con las Oficinas del Nivel de Atención en Comunidad (ONAC) del país, tras el dictado de suspensiones del proceso a prueba, conciliaciones, ejecución condicional de la pena y proceso de justicia restaurativa
