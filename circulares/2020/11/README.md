# Circular 11

Obligación de los Tribunales y Juzgados Penales de país, de comunicar al Colegio de Abogados y Abogadas de Costa Rica, cuando un abogado que se encuentre privado de libertad sin sentencia condenatoria, para que el citado colegio proceda
