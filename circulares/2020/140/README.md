# Circular 140

Circulares aplicables por los despachos judiciales de materia penal ubicados en las zonas en las que el P.E decrete alerta roja, naranja y amarilla debido al COVID-19, y que serán de acatamiento obligatorio durante el lapso en que se mantenga la alerta
