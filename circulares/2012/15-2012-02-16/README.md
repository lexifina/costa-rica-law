# Circular 15-2012-02-16

Sobre deber de los jueces y juezas de pensiones alimentaria de aplicar el artículo 2 Ley de Pensiones Alimentarias y utilizar todo los medios posibles a su alcance para hacer llegar documentos básicos al expediente antes de rechazar un proceso alimentario
