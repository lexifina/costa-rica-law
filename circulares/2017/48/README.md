# Circular 48

Deber de acatar lo dispuesto en el Manual de Procedimientos de las Comunicaciones por medios Electrónicos de las Oficinas Judiciales, así como la obligación de mantener los buzones limpios de manera que permita el ingreso de los correos electrónicos
