1 | 1.1 | Ingresa al sistema informático denominado Agenda Electrónica Cronos, registrando el nombre de usuario y la contraseña3. | | | | | | | | Nota: La autorización para el uso de este Sistema es indiferente de la materia o despacho judicial. En la Agenda se pueden realizar apuntes (apartar fecha y hora dentro del sistema para realización de una diligencia judicial como son las audiencias preliminares, audiencias de conciliación, debates, entre otros) con la particularidad de cada una de las materias, sea: Penal, Penal Juvenil, Agraria, Contencioso Administrativo, Civil, Cobro Judicial, Familia, Niñez y Adolescencia, Contravencional, Laboral, Notarial, Pensiones Alimentarias, Tránsito y Violencia Doméstica. En el anexo N° 1 se detallan los diversos tipos de asuntos, según materia en que se puede utilizar la Agenda Electrónica.
1.2 | Ingresa a la opción crear nueva solicitud o señalamiento según sea el caso, e incluye la información requerida del apunte: Asunto, descripción, tipo de solicitud, estado del señalamiento, fecha y hora de inicio y final de la solicitud, NUE/Sumaria, cantidad de testigos, prioridad y los participantes del señalamiento.4 | | | | | | | | Nota: Este paso es genérico, donde cada persona que utilice el sistema deberá crear el señalamiento para su diligencia propia de la materia (ver Anexo N°1), lo cual es indistinto para el Sistema. A manera de ejemplo se tiene que en materia Penal la Jueza o Juez Decisor, Jueza o Juez Coordinador o en su efecto Jueza o Juez de Trámite, deberá agendar los debates unipersonales, colegiados y cualquier otra diligencia oral, según se establece en el protocolo para el uso de la agenda electrónica en los tribunales de justicia del Poder Judicial (Circular No. 016-2013). En las demás materias, se deberá ingresar la información que sea pertinente a la luz de la materia específica y de la diligencia en particular.
1.3 | Selecciona la opción de guardar para que la información quede registrada, y en el caso de los tribunales y juzgados que requieran asignación de Sala para audiencias o debates, el apunte será enviado como solicitud a la Administración u Oficina encargada de la asignación de salas de juicio. | | | | | | | | Nota: Los despachos de materias no penales que requieran la participación de una Fiscala o Fiscal y/o de una Defensora o Defensor, así como apartar una sala de juicio para realizar un señalamiento, tendrán que registrar la solicitud en el sistema Agenda Electrónica Cronos, y esperar la aprobación de la Administración Regional, según se establece en la Circular No. 016-2013. En el caso de los despachos judiciales que no requieren asignación de sala de juicio porque realizan la audiencia en la oficina, sólo se guarda la información y finaliza el proceso.
2 | 2.1 | Ingresa al sistema informático denominado Agenda Electrónica Cronos, registrando el nombre de usuario y la contraseña. | | | | | | | | Nota: Este paso es genérico y es indiferente al tipo de materia de que se trate.
2.2 | Carga las solicitudes de los apuntes de la agenda en general o da la opción para revisar los señalamientos por día que están pendientes. | | | | | | | | Nota: Deberá ingresar los señalamientos a la Agenda Electrónica Cronos por lo menos una vez durante la primera audiencia y una durante la segunda, con el propósito de aprobar los señalamientos ingresados que se encuentran pendientes.
2.3 | Abre el apunte pendiente, cambia la hora de la solicitud y cambia el estado a aprobado y asigna el número de sala en que corresponderá realizar la audiencia5. | | | | | | | | Nota: En el transcurso de la aprobación se pueden dar varias advertencias, una es que se le indique a la P.P.A. que la sala está ocupada por lo que deberá cambiar la sala o que se dé un choque con alguna/o de los participantes. Cualquiera que sea la situación, la Administración lo comunicará al despacho ya sea por vía telefónica o medio electrónico (Circular N° 016-2013).
| 2.4 | Guarda el apunte para que quede en la bandeja de aprobados6. | | | | | | | | Nota: La Administración comunicará al despacho ya sea por vía telefónica o medio electrónico que el señalamiento fue aprobado, en apego a la Circular No. 016-2013.
3 | 3.1 | Ingresa al sistema informático denominado Agenda Electrónica Cronos y verifica la aprobación del señalamiento. | | | | | | | | Nota: En caso de que se requiera revocar un juicio que corresponde a otra sede, se coordina con la Administración Regional correspondiente, para que esta sede conozca del juicio. Asimismo, se debe corroborar que el juicio por este delito no se haya revocado varias veces ya que, únicamente se revocan juicios de años recientes. Se procura que el delito no sea sexual ni un caso que involucre a un adulto mayor o de población indígena. En caso de que se presente un señalamiento o una continuación, se cuenta con acceso a la Agenda Electrónica Cronos en las Salas de Juicio, para que se pueda corroborar y evitar choques. Lo anterior según se establece en el protocolo para el uso de la agenda electrónica en los tribunales de justicia del Poder Judicial (Circular No. 016-2013).
4 | 3.2 | Incluye en la Agenda Electrónica Cronos el resultado final del evento agendado, sea pendiente, continuación, realizado, sin efecto, suspendido, y el nombre de la Jueza o Juez que resolvió7, y guarda los apuntes para cerrar la gestión. | | | | | | | | Nota: Después de un día de haberse efectuado la diligencia, cuando la persona usuaria vuelve a abrir el apunte, la Agenda Electrónica Cronos le envía un mensaje indicando como recordatorio que debe cambiar el resultado y anota el nombre de la Jueza o Juez que resolvió.

Notas:
1 | La elaboración de manuales de procedimientos institucionales se justifica en el artículo 15 de la Ley General de Control Interno que señala como responsabilidad del jerarca:“Documentar, mantener actualizados y divulgar internamente, las políticas, las normas y los procedimientos de control que garanticen el cumplimiento del Sistema de Control Interno institucional…”
2 | Una característica de este sistema es que los apuntes los puede realizar cualquier funcionario o funcionario/servidora o servidor de cualquier despacho judicial, de cualquier materia, cuyo único requisito es que sea autorizado, o sea que cuente con los permisos respectivos por parte de la Dirección de Tecnología de la Información. Por lo anterior el uso de esta Manual dependerá de la distribución interna del trabajo. En el caso de la materia Contencioso Administrativa, designaron esta actividad a la Jueza o Juez, según se establece en el Protocolo de Salas de Juicio del Anexo A del II Circuito Judicial de San José aprobado por la Comisión de lo Contencioso Administrativo. (Ver Anexo No. 2)
3 | Estos datos son personales y usualmente son las mismas credenciales que se utilizan para ejecutar otras aplicaciones en el Poder Judicial.
4 | Algunos datos los toma automáticamente del Sistema Costarricense de Gestión de los Despachos Judiciales. Indistintamente de la materia que trate ingresa la misma información. En cuanto a los despachos mixtos debe ingresar la misma información pero para cada materia en forma individual, con el fin de poder disponer de la información de forma particular. Asimismo, es importante indicar que al asignar las fiscalas o fiscales, defensoras o defensores, lo deben hacer por número de puesto o plaza de la o del profesional, y no por el nombre, de tal forma que cuando se venga a sustituir a alguno/a de estos profesionales, ya sea por vacaciones, incapacidad, capacitaciones u otro motivo, la información quedará asociada al código de plaza de la o del titular, lo que permitirá ver los apuntes que tenga la o el profesional en la agenda cronos.
5 | El orden de aprobación que realizará la Administración Regional está sujeto a la ordenación automática que realiza el sistema, indistintamente de la materia de que se trate. La ordenación es por fecha y hora del señalamiento que se registró en el sistema. Este esquema únicamente puede romperse cuando se presenten las prioridades de urgencia, sea visitas carcelarias, reos presos, continuaciones, prescripciones, reconocimientos físico, vistas, anticipos jurisdiccionales de prueba, asuntos de Penal Juvenil y Penal de adultos, según se establece en el Protocolo para el Uso de la Agenda Electrónica en los Tribunales de Justicia del Poder Judicial, aprobado por el Consejo Superior en sesión N°109-12 del 18 de diciembre de 2012, artículo LXXVII (Circular No. 016-2013).
6 | Una vez aprobado, automáticamente la Agenda Electrónica Cronos envía un mensaje de texto, a las personas intervinientes que dentro del Sistema Costarricense de Gestión de los Despachos Judiciales incluyeron su número telefónico, para que enviaran mensajes de texto de tipo recordatorio, en caso de que exista alguna diligencia o evento.
7 | Esto por cuanto en algunos casos la Jueza o Juez asignado es diferente a la o al que resolvió la diligencia.
