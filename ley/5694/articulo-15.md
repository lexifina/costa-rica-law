ARTICULO 15.- Las actividades consideradas en este artículo pagarán
el impuesto de patente, conforme al criterio que se indica para cada una
de ellas:
a) Bancos y Establecimientos Financieros (casas de banca, de cambio,
financieras y similares e institutos aseguradores. Se excluyen los Bancos
del Estado).
Pagarán por cada trimestre, sobre ingresos por intereses brutos o por
comisiones, o por ambos, percibidos en el año anterior:
A menos del 8% anual ... ... ... ... ... ... ... ... 3 X 1.000 trimestral
Al 8% anual ... ... ... ... ... ... ... ... ... ... 4 X 1.000 trimestral
A más del 8% anual. ... ... ... ... ... ... ... ... 5 X 1.000 trimestral
Mínima. ... ... ... ... ... ... ... ... ... ... ... ¢ 500.00 trimestrales
b) Comercio de Bienes Inmuebles. Pagarán por cada trimestre, sobre
comisiones percibidas el año anterior; 3 X 1.000 trimestral.
Mínima. ... ... ... ... ... ... ... ... ... ... ... ¢ 500.00 trimestrales
c) Barberías, Establecimientos de Belleza y Estética Física.
Pagarán conforme a la tabla del artículo 17 de esta ley.
d) Máquinas de Juego (en las que el usuario no perciba premios en
dinero efectivo).
Por cada máquina... ... ... ... ... ... ... ... ... ¢ 40.00 trimestrales
e) Billares y Similares.
Por cada mesa ... ... ... ... ... ... ... ... ... ¢ 25.00 trimestrales
f) Salón de Diversiones.
Que explotan juegos de habilidad o aleatorios o ambos permitidos por
ley.
Primera categoría.. ... ... ... ... ... ... ... ...¢ 5,000.00 trimestrales
Segunda categoría.. ... ... ... ... ... ... ... ... 3,000.00 trimestrales
Tercera categoría.. ... ... ... ... ... ... ... ... 1,000.00 trimestrales
Mínima. ... ... ... ... ... ... ... ... ... ... ... 100.00 trimestrales
La Municipalidad establecerá estas categorías, tomando en cuenta la
ubicación, número de mesas de juego o similares, la calidad y presentación
del local y la circunstancia de si el salón es exclusivo para la actividad
o si bien, es complementario de otras principales dentro del mismo
edificio.
g) Servicio de Almacenaje. (Almacenes de depósito y similares) 0.5
por ciento anual sobre la entrada bruta del año anterior, pagadero en
cuatro tractos trimestrales iguales.
h) Estacionamientos. (Comerciales, para vehículos automotores).
Primera categoría - Solares dedicados a la presentación del
servicio, no incluidos en la siguiente categoría, ¢ 1.50 trimestral por
metro cuadrado del área destinada para el uso y control de la actividad.
Segunda categoría - Edificios destinados total o parcialmente a la
presentación de este servicio ¢ 1.00 trimestrales por cada metro cuadrado
del área destinada para el uso y control de la actividad.
i) Agentes Representantes de Casas Extranjeras. Pagarán
trimestralmente la tarifa que les corresponda conforme al artículo
anterior, considerando únicamente como factor impositivo la renta líquida
gravable.
Están incluidos dentro de esta clasificación aquellas personas
físicas o jurídicas que ejercen únicamente esta actividad, incluyendo las
importaciones que deban hacer para dar cumplimiento a licitaciones
adjudicadas, por instituciones públicas. Cuando alguna de esta personas,
además de la representación de casas extranjeras, realice cualquier otro
tipo de actividad lucrativa simultáneamente, se le aplicará la tarifa
establecida en el artículo 14 anterior.
j) Agencias de Publicidad. Pagarán trimestralmente la tarifa que les
corresponda conforme al artículo anterior, considerando únicamente como
factor impositivo la renta líquida gravable.
