Artículo 16.—Régimen de Tributación Simplificada. A los patentados que se encuentren bajo el Régimen de Tributación Simplificada se les aplicará, sobre las compras declaradas, un treinta por ciento (30%) para obtener el ingreso bruto; para ello deberán entregar las fotocopias de las declaraciones que presenten durante el año. Tomando como base este porcentaje, se aplicará el artículo 4 de la presente Ley.
