# Acuerdo municipal (2015-07-13)

No se aplicará transitorio V de Ley N° 9071 no se revisarán y corregirán todas declaraciones de bienes inmuebles efectuadas anteriormente por pequeños y medianos productores agropecuarios y se aplicará un porcentaje del 15% de aumento sobre valores fincas
