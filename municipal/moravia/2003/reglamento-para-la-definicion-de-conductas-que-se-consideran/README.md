# Reglamento municipal (2003-10-27)

Reglamento para la definición de conductas que se consideran contrarias a la ley, la moral y las buenas costumbres y constituirán causales de incumplimiento de los requisitos que exigen las leyes para el desarrollo de la respectiva actividad comercial
