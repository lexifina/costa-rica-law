# Acuerdo municipal (2011-04-27)

Se acuerda declarar Pro tempore durante 6 meses, prorrogables por induvio pro natura una moratoria para la siembra y establecimiento de nuevas áreas de explotación, producción y agroindustria de monocultivo en la parte sur del cantón
