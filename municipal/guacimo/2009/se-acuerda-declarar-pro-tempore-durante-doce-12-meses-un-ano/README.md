# Acuerdo municipal (2009-03-17)

Se acuerda declarar Pro tempore durante doce (12) meses, (un año) prorrogable, para la siembra y establecimientos de nuevas áreas de explotación, producción y agro industrial de piña, una moratoria en la parte sur del cantón
