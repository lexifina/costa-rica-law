# Acuerdo municipal (2007-05-14)

Se suspende el otorgamiento de todo tipo de permiso de construcción o desfogue de aguas para proyecto urbanísticos habitacionales que pretendan desfogar aguas pluviales y/o sanitarias en la Quebrada Seca-Burío
