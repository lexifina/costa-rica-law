# Acuerdo municipal (2021-02-03)

Para gestionar licencias comerciales en el que se haga uso de obras musicales y/o de espectáculos públicos en las que se realice comunicación pública de obras musicales (uso de música), se deberá aportar la licencia de uso de repertorio musical
