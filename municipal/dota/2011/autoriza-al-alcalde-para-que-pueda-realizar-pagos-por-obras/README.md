# Acuerdo municipal (2011-03-24)

Autoriza al Alcalde para que pueda realizar pagos por obras, bienes y servicios, sin fraccionamiento, que se lleven a cabo en la Municipalidad, hasta por la suma de dos millones trescientos mil colones (¢2.300.000)
