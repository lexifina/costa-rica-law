# Acuerdo municipal (2010-07-01)

Para el otorgamiento de permisos de concesiones en la Zona marítima terrestres es necesario presentar Certificación de Patrimonio Natural del Estado vigente para comprobar que la parcela solicitada no se contrapone con el Patrimonio Natural del Estado
