# Acuerdo municipal (2014-04-15)

Declara moratorio a cualquier Proyecto hidroeléctrico dentro del territorio del Cantón de Coto Brus, hasta que se cuente con el consentimiento libre, previo e informado (CCLPI) de las comunidades que se consideran afectadas
