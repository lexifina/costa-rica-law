Artículo 2º—Objetivos específicos.
1) Identificar, documentar, y subsanar las inconsistencias de la base de datos, mediante el estudio de los registros (números de cédula, números de fincas duplicadas, nombres de contribuyentes, nombres sin cédula, basura, cobros, ubicación geográfica, dirección, valores, origen, entre otros).
2) Establecer por proceso, un plan de depuración de la base de datos y un manual para correcta ejecución de la depuración.
3) Reducir las inconsistencias de la base de datos.
4) Efectuar la depuración de manera ordenada por bloques de acuerdo con cada distrito.
5) Cumplir con los procedimientos y normas legales para corregir la información de la base de datos municipal.
Artículo 2º—Definiciones: para la interpretación correcta del presente reglamento se establecen las siguientes definiciones:
a) Sistema Municipal: Es un modelo de gestión local que articula de manera coordinada los diferentes procesos, departamentos, tecnologías y actores de una Municipalidad, con el fin de optimizar la prestación de servicios públicos. Este sistema integra áreas como planificación, gestión financiera, servicios públicos, ordenamiento territorial y participación ciudadana, bajo un marco normativo como el Código Municipal de Costa Rica, y se apoya en herramientas tecnológicas para centralizar la información y facilitar la gestión.
b) Registro Contable: Información financiera de las cuentas por cobrar reflejada en los estados financieros municipales.
c) Depuración de la base de datos: conjunto de acciones destinadas a eliminar, modificar, corregir, conciliar o actualizar los registros en la base de datos o cualquier inconsistencia en los registros municipales.
d) Depuración general: Proceso extraordinario de revisión integral de la base de datos.
e) Depuración de rutina: acciones permanentes de actualización y conciliación de información.
f) Dar de baja: proceso para ajuste de trimestres según sea el caso, sin eliminar permanentemente la línea de cobro del sistema Municipal ya sea de forma parcial o total.
(Nota de Sinalevi: En la publicación de este reglamento municipal, se consignó dos veces el artículo N° 2.)
