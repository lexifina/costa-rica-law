# Acuerdo municipal (2012-03-12)

La Municipalidad de Pococí no autorizará licencias municipales remociones de tierra ni otorgará licencias constructivas para actividades relacionadas con siembra, y expansión, industrialización, exportación, distribución y comercialización interna de piña
