Artículo 20.—Forma de distribución del contenido de dinero cobrado por este impuesto:
1) 50% para reparación y mejoras de caminos.
2) 25% para uso administrativo.
3) 5% para Hogar de Ancianos.
4) 5% para comunidades en acción.
5) 5% para Hogar Transitorio del Niño.
6) 5% para Grupo Mana.
7) 5% para parques y recreación.
