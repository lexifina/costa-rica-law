Artículo 7º—Destino de las becas. Las becas para estudiar se otorgarán como ayudas complementarias para pagar derechos de matrícula o colegiatura (en el caso de las instituciones, para universitarias o técnicas) para compra de uniformes, materiales educativos, transporte o cualquier gasto relacionado con las actividades del estudiante. Las becas que por motivo de pérdida o renuncia quedan vacantes serán asignadas según la lista de postulantes no beneficiarios.
