Artículo 41: Mociones de Orden: Las mociones de orden podrán ser presentadas de manera verbal o escrita siempre y cuando las mismas se presenten para las siguientes razones:
a) Para regular el debate.
b) Para prorrogar el uso de la palabra a un Regidor.
c) Para alterar el orden del día, para incluir un asunto, o para que posponga el conocimiento de uno que se anote en el orden del día.
