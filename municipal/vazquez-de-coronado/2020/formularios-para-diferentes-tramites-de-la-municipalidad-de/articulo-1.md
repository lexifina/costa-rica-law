Segregación: Este se utiliza para saber las posibles divisiones que se pueden realizar en una propiedad. Deberá indicar el (las) área (s) a segregar y el uso que se le dará a la segregación.
Urbanización: Indica si es posible la realización de un desarrollo habitacional de alta o baja densidad.
