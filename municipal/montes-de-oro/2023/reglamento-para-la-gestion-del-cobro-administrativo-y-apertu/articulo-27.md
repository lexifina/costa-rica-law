Artículo 27. Recaudación y pendiente de recaudación por depuración. Una vez conocido y ratificado el informe técnico, se procederá a desafectar la base de datos y por ende se deducirá del Pendiente de Recaudación, dejando para tal caso el contribuyente como "inactivo" cuando corresponda. Para lo cual, esto se deberá indicar junto al nombre como justificación en la base de datos el número de oficio, la que a su vez deberá contar con las firmas aprobatorias.
