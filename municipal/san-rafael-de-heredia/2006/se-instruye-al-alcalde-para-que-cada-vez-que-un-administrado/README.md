# Acuerdo municipal (2006-10-02)

Se instruye al Alcalde para que cada vez que un administrado presente una gestión de permiso en aquellos lotes cuya segregación no haya sido autorizada o cuyo uso no sea conforme con las regulaciones se deniegue los permisos de construcción
