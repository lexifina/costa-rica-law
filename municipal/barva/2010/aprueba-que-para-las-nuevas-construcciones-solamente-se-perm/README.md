# Acuerdo municipal (2010-04-21)

Aprueba que para las nuevas construcciones solamente se permitirá la construcción e instalación de sistemas de tratamiento de aguas negras amigables con el ambiente y no se permitirá más el uso de tanque séptico tradicional
