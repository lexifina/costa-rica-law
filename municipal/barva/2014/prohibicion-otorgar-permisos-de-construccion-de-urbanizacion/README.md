# Acuerdo municipal (2014-08-04)

Prohibición otorgar permisos de construcción de urbanizaciones fraccionamientos con fines urbanísticos, condominios o cualquier otro asentamiento urbano, industrias catalogadas riesgosas para el ambiente, actividades agrícolas intensivas y comercios
