# Acuerdo municipal (2014-08-04)

Establece que hasta que no se realice el estudio integral y de optimización del acueducto de la Municipalidad de Barva y en los distritos que este opere no se otorgarán disponibilidades de agua potable ni visados para la construcción de urbanizaciones,etc
