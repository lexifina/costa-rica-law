# Acuerdo municipal (2014-08-04)

Establece que hasta tanto no se apruebe el plan regulador toda construcción que se autorice en fincas cuya superficie sea igual o mayor de 300 metros cuadrados se exigirá que las aguas llovidas sean desfogadas dentro de la misma propiedad
