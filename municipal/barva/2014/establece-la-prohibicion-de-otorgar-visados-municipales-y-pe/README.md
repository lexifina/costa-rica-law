# Acuerdo municipal (2014-08-04)

Establece la prohibición de otorgar visados municipales y permisos de construcción para establecimiento de urbanizaciones, fraccionamientos con fines urbanísticos, condominios y asentamientos urbanos mientras que no se apruebe un plan regulador
