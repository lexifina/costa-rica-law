# Acuerdo municipal (2017-08-07)

Toda nueva construcción que se autorice en fincas cuya superficie sea igual o mayor de quinientos metros cuadrados se exigirá que las aguas llovidas sean desfogadas y/o resumidas dentro de la misma propiedad
