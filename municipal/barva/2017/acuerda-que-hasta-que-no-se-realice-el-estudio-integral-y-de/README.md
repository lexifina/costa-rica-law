# Acuerdo municipal (2017-04-04)

Acuerda que hasta que no se realice el estudio integral y de optimización del acueducto, en los distritos que opere el acueducto municipal no se otorgaran disponibilidades de agua potable para construcción de urbanizaciones,fraccionamientos ni condominios
