# Acuerdo municipal (2017-03-06)

Para los parámetros para definir las alturas máximas de edificios a construir en el cantón de Grecia, debe aplicarse lo dispuesto en el Capítulo II, Artículo 20, del Plan Regulador Rural y Urbano del cantón de Grecia
