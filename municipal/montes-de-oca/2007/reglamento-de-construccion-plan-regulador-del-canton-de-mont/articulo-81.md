Artículo 81. Las calles internas de un condominio tendrán un ancho mínimo de 7 metros más las aceras como lo establece el artículo 80 de este reglamento. Dichas circulaciones no se consideran como zonas de recreación ni mucho menos están contempladas dentro del porcentaje de áreas verdes, el área para circulación vehicular no podrá exceder en ningún caso el 10% del área total del lote y este porcentaje forma parte del área de cobertura.
