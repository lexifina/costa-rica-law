Capítulo 2. USO HABITACIONAL
Artículo 16. Definiciones de uso Habitacional
Se definirán para efectos de este Reglamento como usos Habitacional: el Uso para habitación, con instalaciones mínimas para su utilización como tal. Estos pueden ser viviendas individuales, viviendas, apartamentos y edificios para alquiler, urbanizaciones, residencias universitarias y estudiantiles y condominios residenciales.
