Artículo 186. Definiciones básicas: Para efectos de este reglamento se tendrán las siguientes definiciones:
a. Área de cobertura permitida (Az): Es el área de cobertura que se permite en cada zona señalada en la Zonificación
b. Área de construcción actual (Aa): es el área que ocupa la construcción actual
c. Número de pisos permitido (N): es el número de pisos permitido en la zona donde se encuentra la edificación que cede los derechos de construcción
d. Área para transferir (At): es el área del terreno a transferir a otra construcción
