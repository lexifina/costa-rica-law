# Acuerdo municipal (2014-11-14)

Establece que para terrenos de uso agropecuario autoriza a la Administración para que pueda incrementar los valores existentes de las fincas de uso agropecuario hasta en un máximo de un veinte por ciento (20%) y reforma acuerdo Nº 5042-2014
