# Acuerdo municipal (2021-11-11)

Anuncia a los administrados que la municipalidad se apega a las Directrices y Disposiciones que fueron emitidas desde el año 1999 hasta el año 2021 por el Órgano de Normalización Técnica del Ministerio de Hacienda
