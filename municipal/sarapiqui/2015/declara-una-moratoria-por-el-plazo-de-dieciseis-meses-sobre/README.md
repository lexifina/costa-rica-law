# Acuerdo municipal (2015-03-30)

Declara una moratoria por el plazo de dieciséis meses sobre la expedición de todo certificado de uso de suelo, permiso de ubicación y construcción de plantas de generación hidroeléctrica en el cantón de Sarapiquí
