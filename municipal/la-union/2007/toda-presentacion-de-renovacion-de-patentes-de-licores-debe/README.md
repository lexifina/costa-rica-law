# Acuerdo municipal (2007-07-12)

Toda presentación de renovación de patentes de licores debe de ir acompañada por un informe de inspección con menos de un mes de realizado y cada solicitud de renovación debe acompañarse por una recomendación de la Jefatura de Patentes
