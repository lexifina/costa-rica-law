Artículo 94.—Usos. Se establecen como usos para esta Zona los siguientes:
Usos compatibles.
Servicios de oficina (2.1, 2.2)
Servicios para el comercio y abasto (3.5, 3.8, 3.9)
Servicios para la salud (4.1)
Servicios para la educación (5.1, 5.2, 5.3, 5.4)
Usos condicionales.
Ninguno que no esté relacionado con la prestación de servicios para la salud
Usos incompatibles.
Habitación (1.1, 1.2)
Servicios funerarios (10.2)
Servicios para el comercio y abasto (3.1, 3.2, 3.3, 3.4, 3.6, 3.7, 3.10, 3.11, 3.12, 3.13, 3.14, 3.15, 3.16)
Servicios para la salud (4.2, 4.3)
Servicios para la cultura y el deporte (7.1, 7.3, 7.4, 7.5)
Alojamiento (8.1)
Seguridad (9.1)
Transporte y comunicación (11.1, 11.2, 11.3)
Industria (12.1)
Instalaciones para la infraestructura (13.1, 13.2)
