Artículo 61.—Usos (HRC). Se establece como usos a las zonas de hábitat rural mixto residencial-comercial los siguientes:
Usos compatibles.
Habitación (1.1, 1.2)
Servicios para el comercio y abasto (3.1)
Servicios para la salud (4.1)
Servicios para la educación (5.1)
Servicios para la cultura y el deporte (7.6)
Usos condicionales.
Servicios de oficina (2.1, 2.2)
Servicios para el comercio y abasto (3.2, 3.3, 3.4, 3.5, 3.9, 3.12)
Servicios para la salud (4.2, 4.3)
Servicios para la educación (5.2, 5.4)
Servicios religiosos (6.1)
Servicios para la cultura y el deporte (7.1, 7.2)
Seguridad (9.1)
Transporte y comunicación (11.1)
Usos incompatibles.
Servicios para el comercio y abasto (3.6, 3.7, 3.8, 3.10, 3.11, 3.13, 3.14, 3.15, y 3,16)
Servicios para la educación (5.3)
Servicios para la cultura y el deporte (7.3, 7.4, 7.5)
Alojamiento (8.1)
Servicios funerarios (10.1, 10.2)
Transporte y comunicación (11.2, 11.3)
Industria (12.1)
Instalaciones para la infraestructura (13.1, 13.2)
