# Acuerdo municipal (2009-02-16)

Declara la micro-cuenca del río Bermúdez que esté dentro de los límites del cantón de San Pablo, como Zonas de Protección Acuífera con el objetivo de proteger y conservar los recursos hídricos superficiales y subterráneos
