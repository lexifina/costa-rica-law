El Concejo Municipal de Orotina acuerda aprobar el siguiente manual:
MANUAL DE PROCEDIMIENTOS DE CONTROL INTERNO
PARA EL MANEJO DE CAJA RECAUDADORA, LA FUNCIÓN
DE TESORERÍA, FACTURACIÓN Y COBROS
Y CONTABILIDAD EN ESTE PROCESO
CAPÍTULO I
Disposiciones generales
Artículo 1º—Contenido y aplicación. Este manual establece controles internos mínimos, para el manejo de caja recaudadora a la función de tesorería, facturación y cobros y contabilidad en este proceso. El manual es de aplicación obligatoria para aquellas oficinas y funcionarios que se involucran.
