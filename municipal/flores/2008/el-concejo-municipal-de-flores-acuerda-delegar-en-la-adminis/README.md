# Acuerdo municipal (2008-08-19)

El Concejo Municipal de Flores acuerda delegar en la administración municipal las siguientes funciones: aprobación de licencias para autorización de actividades lucrativas (patentes) y aprobación de solicitudes de visados municipales en planos catastrados
