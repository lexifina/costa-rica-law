Artículo 191.—Prohibición de uso de las vías públicas urbanas:
a. Usar las vías públicas para aumentar el área utilizable de predio o de una construcción, tanto en forma aérea, como subterránea;
b. Usar las vías públicas para establecer puestos con fines comerciales de cualquier clase;
c. Colocar postes, cobertizos, o quioscos de publicidad;
d. Instalar aparatos y recipientes para desechos sólidos que entorpezcan el tránsito.
