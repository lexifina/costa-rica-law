# Resolución 313

Establece disposiciones para la aplicación de beneficios a las personas físicas o jurídicas exportadoras autorizadas como Operador Económico Autorizado (OEA) bajo el Programa de Facilitación Aduanera para el Comercio Confiable en Costa Rica
