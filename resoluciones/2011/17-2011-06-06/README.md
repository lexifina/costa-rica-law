# Resolución 17-2011-06-06

Establece trámite para documentos donde se constituya, se reorganice una Organización de Desarrollo Comunal, se renueve la Junta Directiva se realicen elecciones parciales de miembros de Junta Directiva y nombramiento de miembros suplentes Junta Directiva
