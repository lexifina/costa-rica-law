# Resolución 37

Autoriza al Registro Nacional, previa calificación, a inscribir bienes fideicometidos que corresponda, en favor del fiduciario exentos de todo pago por concepto de derechos de registro y demás impuestos que se deban cancelar por motivo de tal inscripción
