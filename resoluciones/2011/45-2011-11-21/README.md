# Resolución 45-2011-11-21

Establece la aplicación de medidas antidumping a las importaciones de pinturas de látex a base de agua originarias de los Estados Unidos de América que de conformidad con el Sistema SAC que ingresen a Costa Rica bajo la partida arancelaria 3209.90.10.00
