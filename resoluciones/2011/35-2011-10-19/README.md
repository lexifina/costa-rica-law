# Resolución 35-2011-10-19

Reforma Establece que la base imponible del Impuesto Solidario para el Fortalecimiento de Programas de Vivienda (en adelante Impuesto Solidario) estará constituída por el valor fiscal del bien inmueble de uso habitacional
