# Resolución 1-2011-01-18

Acuerda permitir la aplicación de autorizaciones de exención fiscal genéricas transmitidas a la aplicación informática TICA, emitidas con anterioridad a la apertura arancelaria para la implementación de los Convenios Ambientales Multilaterales
