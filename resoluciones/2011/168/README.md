# Resolución 168

Comunica que la Gerencia de Operaciones de la Promotora de Comercio Exterior estará encargada de transmitir al Sistema Informático TICA las inclusiones, modificaciones y anulaciones del documento 0327 denominado “Detalle de las mercancías de PA”
