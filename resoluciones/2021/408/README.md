# Resolución 408

Asocia incisos arancelarios a la Nota Técnica N°0073 correspondientes a sustancias químicas que afectan la capa de ozono, para los regímenes de importación, exportación y tránsito y elimina incisos arancelarios a la nota técnica N°0038 para los regímenes

- Número: 408
- Fecha: 2021-11-09
