# Resolución 109

Se tiene como puesto aduanero las Tablillas, las oficinas aduaneras ubicadas en la zona fronteriza entre Costa Rica y Nicaragua, en la localidad de Las Tablillas, adscrito a la Aduana de Peñas Blancas
