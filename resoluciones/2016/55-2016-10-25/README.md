# Resolución 55-2016-10-25

Reforma Resolución N° 030-2009 Establece que la base imponible del Impuesto Solidario para el Fortalecimiento de Programas de Vivienda (en adelante Impuesto Solidario) estará constituida por el valor fiscal del bien inmueble de uso habitacional
