# Resolución 1-2016-01-07

La Dirección de Fiscalización para ejecución de planes anuales de fiscalización podrá seleccionar sujetos pasivos delimitados por diferentes criterios establecidos en el Reglamento sobre Criterios Objetivos de Selección de Contribuyente para Fiscalización
