# Resolución 689

Autoriza temporalmente a todas las unidades de transporte de combustible que tengan vencida su autorización para operar por el incumplimiento de las pruebas técnicas a que hace referencia el decreto ejecutivo 32921 para que puedan transportar combustible

- Número: 689
- Fecha: 2010-11-04
