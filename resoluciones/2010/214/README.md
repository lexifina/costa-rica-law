# Resolución 214

Informa a partir del 28/06/2010, el sistema informático TICA no permite la importación temporal categoría estatal y subcontrato/concesión obra pública, de las mercancías de partidas 87.02 y 87.03, se habilita en la partida 87.04 la Importación Temporal
