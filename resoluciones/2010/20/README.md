# Resolución 20

Concede autorización genérica a Juntas Educación y Juntas Administrativas de Instituciones Enseñanza para adquirir bienes y servicios en mercado nacional exentos Impuestos General sobre Ventas y/o Selectivo Consumo se prescindirá de trámite de exoneración
