# Resolución 574

Aclara plazo otorgado por resolución R-D-319-2010 en el sentido de que la fecha límite para la presentación de la certificación de las pruebas técnicas solicitadas a los prestadores de servicio público de transporte de combustibles “CR”, vence 04/11/2010
