# Resolución (2014-09-23)

Delega en el encargado del Proceso de Patentes el deber de iniciar e instruir los procedimientos administrativos para determinar la procedencia del cobro de multa para los titulares de licencias de licores que incurran en faltas que ameriten sanciones
