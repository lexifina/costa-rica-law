# Resolución 16-2014-03-05

Establece normas para que las Asociaciones y Fundaciones de Cuidados Paliativos sean beneficiarias de la exoneración de la ley N° 9140 "Exoneración a las Asociaciones y la Fundaciones que apoyan a las unidades de cuidados paliativos"
