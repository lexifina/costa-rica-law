# Resolución 52-2014-12-19

Estarán no afectos al pago del Impuesto sobre Bienes Inmuebles para el período 2015 aquellos inmuebles que constituyan bien único de los sujetos pasivos, personas físicas y cuyo valor, registrado en la respectiva Municipalidad, no exceda de ¢18.153.00
