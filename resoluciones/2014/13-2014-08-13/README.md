# Resolución 13-2014-08-13

Establece un 14.95% para la tasa de intereses legales a cargo del sujeto pasivo y de la administración tributaria, de conformidad con lo regulado en los artículos 57 y 58 del Código de Normas y Procedimientos Tributarios
