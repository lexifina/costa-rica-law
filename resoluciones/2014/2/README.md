# Resolución 2

Estarán no afectos al pago del Impuesto sobre Bienes Inmuebles para el período 2014 todos aquellos inmuebles que constituyan bien único de los sujetos pasivos, personas físicas y cuyo valor registrado en la Municipalidad no exceda de ¢17.973.000,00
