# Resolución 10-2014-03-10

Establece una exoneración de un 100%, 50% y un 25% a los usuarios de SENASA que apliquen la tarifa KG.04 relativa a "Aislamiento viral y KG.05 "Prueba de Hemaglutinación Aviar"
