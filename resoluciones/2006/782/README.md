# Resolución 782

Comunica a transportistas terrestres que efectúan tránsitos nacionales e internacionales en calidad de Auxiliares de Función Pública Aduanera el procedimiento ha seguir para inscripción y desinscripción de conductores, vehículos, carretas y similares
