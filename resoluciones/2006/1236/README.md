# Resolución 1236

Declaratoria de Elección de Regidores que integrarán las Municipalidades de los Cantones de la Provincia de Heredia, durante el período constitucional que se iniciará el primero de mayo del dos mil seis y concluirá el treinta de abril del dos mil diez
