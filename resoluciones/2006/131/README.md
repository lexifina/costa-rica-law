# Resolución 131

Comunica Plan de Contingencia año 2006 para la Continuidad de Operaciones de la Aduana Santamaría, el cual será de acatamiento obligatorio para los funcionarios del Servicio Nacional de Aduanas, Auxiliares de la Función Pública Aduanera y demás usuarios
