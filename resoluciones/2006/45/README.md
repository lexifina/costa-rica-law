# Resolución 45

Las Municipalidades del país y cualquier forma de asociación entre ellas, no deberán remitir gestiones tendentes a obtener autorización de la Contraloría General para la contratación de préstamos municipales

- Número: 45
- Fecha: 2006-05-11
