# Resolución 1235

Declaratoria de Elección de Regidores que integrarán las Municipalidades de los cantones de la Provincia de Cartago, durante el período constitucional que se iniciará el primero de mayo del dos mil seis y que concluirá el treinta de abril del dos mil diez
