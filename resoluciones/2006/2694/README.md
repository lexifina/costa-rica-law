# Resolución 2694

La prohibición del numeral 85 inciso j) Código Electoral aplica para campañas de información, divulgación de temas de interés nacional en que trabaja el Gobierno de la República y si dicha restricción rige para las próximas elecciones 3 de diciembre 2006
