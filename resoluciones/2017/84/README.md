# Resolución 84

Concede cuarta autorización genérica por 2 año a favor del Proyecto "Implementación del Programa Nacional de Corredores" para que adquiera bienes y servicios en el mercado nacional exentos de los Impuestos General sobre las Ventas y/o Selectivo de Consumo
