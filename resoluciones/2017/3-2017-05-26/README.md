# Resolución 3-2017-05-26

Establece en 10.92% anual la tasa de interés tanto a cargo del sujeto pasivo, como a cargo de la Administración Tributaria, de conformidad con lo regulado en los artículos 57 y 58 del Código de Normas y Procedimientos Tributarios
