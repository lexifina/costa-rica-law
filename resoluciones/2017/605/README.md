# Resolución 605

Concede liberación de tributos exonerados al momento de adquisición de materiales que corresponden a chatarra: platinas metálicas, varillas, hojalatería de canoas botaguas y cumbreras, conduit eléctrico, latas metálicas de techo láminas de soportería etc
