# Resolución 103

Permite como excepción la derriba controlada en las plantaciones de piñas ubicadas en las comunidades de Piedra Alegre, Santa Elena, Coope Isabel, Los Ángeles, El Encanto, Cuatro Esquinas, Puerto Escondido, La Comarca, San Luis, El Palmar y La Legua
