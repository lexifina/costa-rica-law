# Resolución 9-2017-02-09

Permite la aplicación de las autorizaciones para adquirir mercancías sin el pago de los impuestos de ventas y consumo, emitidas con anterioridad al 1° de enero del 2017 por las administraciones tributarias de la Dirección General de Tributación

- Número: 9
- Fecha: 2017-02-09
