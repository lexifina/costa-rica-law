# Resolución 16-2017-02-28

Establece en 11.73% la tasa de interés tanto a cargo del sujeto pasivo, como a cargo de la Administración Tributaria, de conformidad con lo regulado en los artículos 57 y 58 del Código de Normas y Procedimientos Tributarios
