# Resolución 69-2019-11-27

La Dirección de Fiscalización de DGT para sus planes anuales de fiscalización podrá seleccionar además de los establecidos en Reglamento Criterios Objetivos Selección Contribuyente para Fiscalización los definidas según clasificación Internacional (CIIU)
