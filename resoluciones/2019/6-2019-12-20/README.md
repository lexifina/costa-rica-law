# Resolución 6-2019-12-20

Aclara que el salario mínimo para los trabajadores periodistas será el fijado para las categorías salariales según corresponda de Bachiller Universitario o Licenciado Universitario del artículo 1 inciso b) "Ocupaciones Genéricas por Mes
