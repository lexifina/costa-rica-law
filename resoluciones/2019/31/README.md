# Resolución 31

Autoriza al Departamento de Gestión de Exenciones para conceder autorización de exención genérica del Impuesto sobre el Valor Agregado hasta el 30 de junio del 2020 sobre los servicios de ingeniería, arquitectura, topografía y construcción de obra civil
