# Resolución 39

Autoriza al departamento de gestión de exenciones para conceder ordenes especiales a favor de los proveedores de la CCSS así como de Corporaciones Municipales para adquirir bienes y servicios necesarios sin el pago del Impuesto Sobre el Valor Agregado
