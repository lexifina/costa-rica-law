# Resolución 47

Establece una exoneración parcial de un 30 % a los usuarios de SENASA que apliquen la tarifa F.01 relativo a “Registro o Renovación de registro de materias primas, mezclas, premezclas y alimentos balanceados para animales (por producto, cada 5 años)”
