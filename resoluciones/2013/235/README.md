# Resolución 235

A partir del 1° de agosto del 2013 se incicia el cobro del impuesto de 25 dólares en las declaraciones aduaneras de exportación de mercancías que salgan por puestos fronterizos terrestres y publica Mensaje de Declaración Aduanera Versión 3.7
