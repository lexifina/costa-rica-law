# Resolución 22-2013-05-27

Ordena inhabilitación Código Tributario B08 (B.08.01; B08.02; B.08.03) en Sistema Automatizado de Control de Ingresos (SACI) y establecer un establecimiento para exportación productos de origen animal deberá cancelar tarifa establecida en el Código B.
