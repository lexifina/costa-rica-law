# Resolución 20-2013-05-14

Todas las autorizaciones otorgadas por la Administración Tributaria mediante los Convenio Tributarios que estén vigentes y no tengan fecha de vencimiento quedarán sin efecto a partir del período fiscal 2014

- Número: 20
- Fecha: 2013-05-14
