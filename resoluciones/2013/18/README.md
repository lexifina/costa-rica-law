# Resolución 18

Establece que para la importación de vehículos usados se deberá adjuntar a la declaración aduanera dos nuevos documentos obligatorios: “Declaración Jurada Protocolizada art. 5 Ley de Tránsito” código 0353 y “Título de Propiedad” código 0114
