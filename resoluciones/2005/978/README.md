# Resolución 978

Interpreta el artículo 74 del Código Electoral en el párrafo cuarto sobre si la prohibición propagandística que pesa sobre los precandidatos oficiales abarca el uso de medios alternativos de comunicación como lo son el correo eléctrico e internet
