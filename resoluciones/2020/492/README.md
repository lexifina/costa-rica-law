# Resolución 492

Habilita a partir del 9/11/2020 la automatización de los distintos tractos de exoneración de impuestos de vehículos eléctricos basado en la ley 9518 de “Incentivos y Promoción para el Transporte Eléctrico”, en el sistema informático TIC@
