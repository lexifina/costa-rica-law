# Resolución 343

Reforma Lineamientos para regular el ingreso y salida de vehículos y mercancías, conducidas por transportistas nacionales o extranjeros que van a realizar operaciones de desenganche y enganche en la zona primaria de Peñas Blancas y el Puesto Tablillas
