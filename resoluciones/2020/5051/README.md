# Resolución 5051

Establece autorización para la CCSS por parte del Ministerio de Salud para que las personas funcionarias que realicen notificación de eventos de salud estén facultados para emitir la orden sanitaria correspondiente por COVID-19

- Número: 5051
- Fecha: 2020-07-11
- Ente emisor: Ministerio de Salud
