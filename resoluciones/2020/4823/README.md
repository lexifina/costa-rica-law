# Resolución 4823

Ordena el cierre temporal de todos los establecimientos con permiso sanitario de funcionamiento que brinden atención al público, desde las 00:00 horas del sábado 20, domingo 21 y lunes 22 de junio hasta las 5:00 horas inclusive

- Número: 4823
