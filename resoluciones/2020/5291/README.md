# Resolución 5291

Deja sin efecto resolución cierre temporal de establecimientos con permiso sanitario de funcionamiento de lunes a viernes de 17:00 horas a las 5:00 horas del día siguiente y cierre temporal de dichos establecimientos los sábados y domingos de manera total
