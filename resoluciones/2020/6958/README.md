# Resolución 6958

Ordena la suspensión temporal de aquellas actividades que favorezcan el surgimiento de una cantidad muy elevada de cadenas de transmisión simultáneas

- Tipo: Resolución
- Número: 6958
- Fecha: 2020-09-08
- Ente emisor: Ministerio de Salud
