# Resolución 109

Establece como requisito de egreso de Costa Rica hacia Nicaragua por vía terrestre, marítima, fluvial o aérea, la obligación de presentar comprobante de haberse realizado dentro de las 72 horas previas, una prueba PCR en tiempo real para COVID-19
