# Resolución 489

Prorroga hasta el 02 de marzo de 2021 inclusive el plazo de permanencia en el país de vehículos terrestres, aéreos o acuáticos, que cuenten con un certificado de importación temporal categoría turista

- Número: 489
- Fecha: 2020-11-02
