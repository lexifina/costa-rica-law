# Resolución 384

Autoriza hasta el 18 de noviembre de 2020, la prórroga del plazo de permanencia en el país de vehículos terrestres, aéreos o acuáticos, que cuenten con un certificado de importación temporal categoría turista

- Número: 384
- Fecha: 2020-07-31
