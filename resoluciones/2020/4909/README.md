# Resolución 4909

Ordena cierre temporal de establecimientos con permiso sanitario de funcionamiento que brinden atención al público de lunes a viernes desde las 17:00 hasta las 5:00 y los días sábado y domingo de manera total en los cantones con alerta naranja
