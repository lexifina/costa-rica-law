# Resolución 81-2020-08-20

Suspende temporalmente las disposiciones tarifarias definidas en el pliego tarifario del servicio de distribución de energía eléctrica para atender los efectos de las medidas sanitarias para la contención del COVID-19 y recuperación económica

- Número: 81
- Fecha: 2020-08-20
