# Resolución 5352

Reforma Establece disposiciones sanitarias dirigidas a las personas extranjeras que ingresen al territorio nacional bajo la categoría migratoria de No Residentes, subcategorías Turismo únicamente vía aérea por la emergencia del COVID-19
