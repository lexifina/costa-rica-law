# Resolución 4547

Reforma Establece medida sanitaria para prohibir el ingreso a las personas en los siguientes ríos del territorio nacional: Medio Queso, Frío, Sistema de Canalización del Caribe Norte (Canales de Tortuguero), Colorado y Sarapiquí, en franja horaria
