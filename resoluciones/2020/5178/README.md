# Resolución 5178

Faculta a las personas colaboradoras en funciones de extensión agropecuaria, así como en inspección, vigilancia y control zoosanitario y fitosanitario dependencias del Ministerio de Agricultura y Ganadería para que emitan orden sanitaria por COVID-19
