# Resolución 2486

Se inhibe personas extranjeras que cuenten con permanencia legal autorizada bajo la categorías migratorias de Residencia Permanente Residencia Temporal Categorías Especiales o No Residentes subcategoría Estancia para que egresen del territorio nacional
