# Resolución 6-2020-08-11

Establece como medida fitosanitaria de cumplimiento obligatorio en todos los puntos de ingreso al territorio nacional el uso de sistemas de desinfección del calzado de pasajeros y tripulaciones de las naves que ingresen al país
