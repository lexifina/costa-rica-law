# Resolución 370

Denomina asignación temporal de funciones adicionales de igual o distinta naturaleza a la posibilidad que tiene el Ministerio de Educación Pública de asignar y remunerar a un funcionario labores de igual o distinta naturaleza a las realizadas de manera cotidiana, en forma temporal y una vez finalizada su jornada regular
