# Resolución 3

Ordena a partir del 01 de abril de 2026, la aplicación del Índice de Precios al Consumidor (IPC) correspondiente al período acumulado a diciembre de 2025, equivalente a una variación interanual negativa del -1,23 %, a las tarifas de cobro de los servicios
