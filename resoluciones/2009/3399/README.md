# Resolución 3399

La inscripción de candidaturas que dará inicio a partir del 1° de octubre de 2009, deberá llevarse a cabo bajo el sistema de cuota mínima del 40% de participación femenina regulado en los artículos 58 inciso n) y 60 del Código Electoral vigente
