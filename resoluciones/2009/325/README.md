# Resolución 325

Requisitos: empresas de Zonas Francas para operar con sistema informático TICA, registrar ante Dirección General de Aduanas una cuenta de fondos a vista y a partir de 11/11/2009 empresa de Zona Franca debe instarlar actualización de certificados digitales
