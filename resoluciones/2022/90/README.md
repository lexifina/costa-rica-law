# Resolución 90

Autorizará la permanencia temporal del vehículo terrestre, aéreo o acuático para uso exclusivo del turista, hasta por el plazo otorgado por la Dirección General de Migración y Extranjería al turista

- Número: 90
- Fecha: 2022-03-29
