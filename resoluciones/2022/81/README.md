# Resolución 81

Declara la nulidad absoluta de la resolución RES-DGA-02-2022 del 05 de enero de 2022, "La autoridad aduanera puede realizar inspecciones con el fin de facilitar la inspección de las mercancías, que ingresan al territorio aduanero nacional"
