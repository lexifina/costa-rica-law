# Resolución 662

No se tramitarán ni aceptarán declaraciones aduaneras de tránsito internacional asociadas a mercancías cargadas en territorio nacional, en la que se consigne como ejecutor o transportista del tránsito internacional a transportista aduanero inscrito Panamá
