# Resolución 258

Se emplearán de forma paralela los casilleros electrónicos y los casilleros físicos existentes en la Dirección General de Aduanas hasta el 30 de junio de 2007; a partir de dicha fecha, sólo se utilizarán los casilleros electrónicos
