# Resolución 22

A partir de 31 de enero de 2007, los ingresos e importaciones de combustibles tramitadas por RECOPE, se realizarán por medio del Sistema Información para Control Aduanero TIC@ y a partir de 31 marzo de 2007 se implementa Sistema TIC@ en aduana Limón
