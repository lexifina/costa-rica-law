# Resolución 313

Comunica a Transportistas Aduaneros Nacionales y Centroamericanos su obligación de transmitir con anterioridad a la llegada de vehículos y mercancías, la información correspondiente al Manifiesto de Carga y/o Declaración de Tránsito Internacional
