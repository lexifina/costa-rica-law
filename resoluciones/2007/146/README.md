# Resolución 146

Comunica Plan de Contingencia para Continuidad de Operaciones de Aduana de Limón, que será de acatamiento obligatorio para funcionarios del Servicio Nacional de Aduanas, Auxiliares de función pública aduanera y demás usuarios del Sistema Aduanero Nacional
