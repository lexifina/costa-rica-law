# Resolución 1012

Tribunal Supremo de Elecciones tiene competencia para realizar remociones en Juntas Cantonales. Para ser miembro de Junta Electoral requisito ser vecino del cantón. Los miembros de Juntas Electorales no tienen limitación en participación política
