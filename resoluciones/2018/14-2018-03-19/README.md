# Resolución 14-2018-03-19

Amplía a 18 meses el plazo para efectos de cumplir con la obligación de presentar el formulario para la declaración y pago de la contribución parafiscal, conforme con el Transitorio I del Decreto Ejecutivo N° 40607-H
