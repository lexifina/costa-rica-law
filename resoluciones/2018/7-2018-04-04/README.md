# Resolución 7-2018-04-04

Establece que extracción de agua para realizar obras de infraestructura pública cuya demanda de agua no supere un volumen máximo diario de 74000 litros catalogan como aprovechamiento temporal de agua que requiere autorización de este Ministerio
