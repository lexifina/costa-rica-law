# Resolución 68-2018-09-25

Autoriza al Departamento de Gestión de Exenciones para conceder autorización genérica de exención para los bienes y materias primas incluidas en los decretos ejecutivos N° 21322-H-S-MEIC, 21719-H-S-MEIC, 22491-S y 31084-MEIC
