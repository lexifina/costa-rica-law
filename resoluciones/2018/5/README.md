# Resolución 5

Concede autorización genérica por 12 meses a favor del Proyecto de Mercado Regional Mayorista de la Región Chorotega, que se llevara a cabo mediante el Programa Integral de Mercadeo Agropecuario a efectos de adquirir bienes y servicios exentos de impuesto
