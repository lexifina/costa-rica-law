# Resolución 25-2018-08-24

Prorroga la habilitación de manera temporal para movilizar unidades de transporte con carga de plátano, banano, piña, aguacate y mango, de la empresa Banapiña Nicaragua, S. A. para ser exportada por Puerto Limón
