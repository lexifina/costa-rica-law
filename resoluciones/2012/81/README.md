# Resolución 81

Revoca resoluciones RSC-016-2009 del 11/3/2009 y RSC-236-2011 del 2/11/2011 y establece requisitos de admisibilidad de solicitudes de autorizaciones para prestar servicios de Internet en la modalidad de "Café Internet"
