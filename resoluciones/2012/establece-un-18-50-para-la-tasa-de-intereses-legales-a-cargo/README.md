# Resolución (2012-07-30)

Establece un 18.50% para la tasa de intereses legales a cargo del sujeto pasivo y de la administración tributaria, de conformidad con lo regulado en los artículos 57 y 58 del Código de Normas y Procedimientos Tributarios
