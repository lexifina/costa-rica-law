# Resolución 34-2012-11-16

Habilita el 16 de noviembre de 2012, para que los contribuyentes del Impuesto General sobre las Ventas y Retenciones en la Fuente, realicen los pagos correspondientes a dichas obligaciones tributarias sin generación de intereses
