# Resolución 56

Establece no imponer medidas definitivas de salvaguardia sobre las importaciones de "Arroz Pilado" que de conformidad con el Sistema Armonizado Centroamericano (SAC) ingresen a Costa Rica bajo las fracciones arancelarias 1006.30.90.91 y 1006.30.90.99
