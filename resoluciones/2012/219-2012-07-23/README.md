# Resolución 219-2012-07-23

Reforma Formato de Mensaje de Declaración Única Aduanera Versión 3.5 y comunica que en la liquidación de impuestos del TICA, se incluirá el cobro de servicios Cuarentenarios de fumigación, aspersión o nebulización
