# Resolución 96

Mantiene RES-DGA-662-2007 y dispone medidas con respecto a transporte de mercancías con declaraciones aduaneras en que se consigne un ejecutor o transportista incrito en Panamá y que así se encuentre registrado en la base de datos de la SIECA.
