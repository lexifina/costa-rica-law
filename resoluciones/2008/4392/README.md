# Resolución 4392

Toda la correspondencia que se reciba en la Superintendencia debe pasar a la oficina de control de correspondencia para obtener el respectivo registro (NOTA: mediante RES-1692 de 20/05/2009 la SUGEF emite regulaciones sobre esta misma materia).
