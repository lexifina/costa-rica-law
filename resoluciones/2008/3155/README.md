# Resolución 3155

Interpreta el artículo 16 del Estatuto del Partido Acción Ciudadana en el sentido que el órgano encargado de reglamentar los procedimientos de afiliación partidaria es el Comité Ejecutivo Superior y no la Secretaría General.
