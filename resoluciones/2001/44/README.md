# Resolución 44

Se otorga hasta un cinco por ciento ( 5% ) de decuentos a los sujetos pasivos que presenten sus declaraciones - autoliquidaciones electrónicamente mediante los sostemas que para tales efectos sean autorizados de confirmidad con la resolución N° 29-2001
