# Resolución 32

Establece que los contribuyentes que perciben el Impuesto General sobre las Ventas por el sistema tradicional y de compras deben liquidarlo con el formulario D104 "Declaración jurada del Impuesto General sobre las Ventas, Liquidación tradicional"
